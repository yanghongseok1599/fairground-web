# 연합팀 이벤트 대항전 — 개발 명세 초안

상태: 현장 노트북용 운영·중계 화면 1차 구현 완료. 사용법과 실제 구현 범위는 [기능 README](../src/features/alliance-event/README.md)를 따른다. 아래 문서는 기존 요구사항과 향후 확장 설계를 포함한다.

현재 구현은 서버 파일 저장과 HTTP 동기화를 사용한다. Supabase 연동이나 운영 사이트 배포는 하지 않았다. 운영 화면 `/events/alliance/{id}/control`과 독립 출력 화면 `/events/alliance/{id}/display`를 제공하며, `npm run dev:event`로 실행한다. 참가팀·선수는 수동 입력하고, 공 살리기 시간/횟수 기준은 편성 시 선택한다. 기권·실격 점수 처리와 기존 회원 DB 연동은 후속 범위다.

## 확정된 요구사항

- 참가팀은 A조 6개 팀, B조 6개 팀으로 총 12개 팀이다.
- 각 조 안에서 기존 참가팀 두 개를 연합팀 하나로 묶는다. A조 연합팀 3개, B조 연합팀 3개로 총 6개 연합팀을 구성한다.
- A조 팀과 B조 팀을 섞어 하나의 연합팀으로 편성하지 않는다. 각 원 참가팀은 정확히 하나의 연합팀에 속한다.
- 연합팀이 직접 새 팀명을 정한다.
- 종목마다 연합팀 소속 선수 중 출전 선수를 선발한다.
- 1종목은 슈팅왕 뽑기다. 사람이 측정한 속도를 운영자가 입력한다.
- 슈팅왕 대표는 연합팀당 남자 1명과 여자 1명, 총 2명으로 선발한다. 최신 남1·여1 요청은 2인 슈팅 대표에 적용한 것으로 해석하며, 공 살리기의 6인 출전은 유지한다.
- 슈팅 속도를 먼저 크게 공개하고, 잠시 후 대결 중인 두 연합팀의 속도 비교 화면으로 전환한다.
- 2종목은 풋살 코트 중앙 원 안에서 6명이 공을 떨어뜨리지 않고 살리는 게임이다.
- 6개 연합팀이 두 이벤트에 모두 참가하고, 두 이벤트의 점수를 합산해 전체 1위 연합팀을 판정하고 공개한다.
- A/B조는 연합팀 편성의 기준이다. 이벤트 성적은 두 조를 합친 6개 연합팀 전체를 대상으로 계산한다.
- 사용자 요청에 따라 슈팅왕 1위 100점, 공 살리기 1위 1,000점으로 배점한다. 최종 최고점은 1,100점이다.
- 공동 우승 없이 최종 1위를 정한다. 공 살리기 하위 순위를 기존 비율로 배점하면 순위 간 차이가 200점이므로, 공 살리기의 단독 1~6위 확정 후 최종 순위는 공 살리기 순위대로 결정된다.

편성 예시이며 실제 짝과 연합팀명은 운영 시 정한다.

| 원 소속조 | 구성팀  | 연합팀 식별자 |
| --------- | ------- | ------------- |
| A조       | A1 + A2 | A연합1        |
| A조       | A3 + A4 | A연합2        |
| A조       | A5 + A6 | A연합3        |
| B조       | B1 + B2 | B연합1        |
| B조       | B3 + B4 | B연합2        |
| B조       | B5 + B6 | B연합3        |

## 확인 대기 및 추천 기본안

사용자에게 확인 중인 항목:

1. 공 살리기 순위를 유지 시간으로 정할지, 연속 터치 횟수로 정할지.

참가 규모, 조 안에서 두 팀씩 묶는 방식, 슈팅 대표 남1·여1, 슈팅왕 1위 100점·공 살리기 1위 1,000점은 반영된 요구사항이다. 아래 시도 기회, 종목별 팀 기록, 공 살리기 구성팀별 배분, 2~6위 배점 및 기록 동률 처리 방식은 추천안이다.

운영 명칭은 슈팅왕을 `보너스 게임`, 공 살리기를 `본게임`으로 소개하는 방향을 제안한다. 점수와 우승 판정 규칙은 두 게임 시작 전에 모두 안내한다.

슈팅 대표 인원을 제외한 아래 기본안은 제안이다. 행사 시작 전에 운영자가 규칙을 확인하고 잠근다.

| 항목                | 추천 기본안                                                              |
| ------------------- | ------------------------------------------------------------------------ |
| 슈팅 출전           | 연합팀당 남자 1명 + 여자 1명. 원 소속팀에서 1명씩 선발하는 것은 권장사항 |
| 슈팅 기회           | 선수당 2회, 대결하는 연합팀이 번갈아 시도                                |
| 개인 슈팅왕         | 모든 유효 시도 중 최고 속도를 기록한 선수                                |
| 슈팅 종목의 팀 기록 | 대표 2명의 개인 최고 속도 평균. 두 선수가 모두 유효 기록을 얻어야 확정   |
| 공 살리기 출전      | 연합팀당 6명, 원 소속팀에서 3명씩                                        |
| 공 살리기 기회      | 연합팀당 2회, 선택한 기준의 더 좋은 기록을 채택                          |
| 종목별 중복 출전    | 기본 허용. 더 많은 선수의 참여를 원하면 행사 설정에서 제한               |
| 기록 공개 시간      | 4초, 설정 가능                                                           |
| 다음 차례           | 운영자의 수동 진행                                                       |

슈팅 팀 기록은 남녀 대표 각각의 최고 속도를 평균하는 방식을 추천한다. `(남자 대표 최고 속도 + 여자 대표 최고 속도) / 2`로 계산해 두 선수의 기록을 모두 반영한다. 개인 최고상과 팀 종목 순위는 분리한다. 평균 계산 전 반올림하지 않고, 화면의 표시 정밀도와 순위 판정 정밀도를 명시한다.

## 연합팀 구성과 출전 명단

- 원래 팀과 선수 소속은 변경하지 않는다. 이벤트 안에 연합팀과 구성팀 연결을 별도로 만든다.
- 연합팀마다 같은 조의 서로 다른 구성팀 두 개, 원 소속조, 새 팀명, 식별 색상을 저장한다.
- 하나의 원 소속팀이 같은 이벤트의 두 연합팀에 중복 편성되지 않도록 검증한다.
- 각 종목 출전 명단은 해당 연합팀의 두 구성팀 선수 중에서 선택한다.
- 슈팅은 서로 다른 선수 2명이면서 남자 1명·여자 1명인지 등록·확인된 선수 정보로 검사한다. 사진이나 이름으로 성별을 추정하지 않는다.
- 공 살리기는 서로 다른 선수 6명이어야 한다. 원 구성팀별 3명씩은 추천이며, 이 종목의 별도 성별 비율은 정해지지 않았다.
- 이번 이벤트는 원 참가팀 12개, 연합팀 6개로 고정한다. A/B 각 조의 6개 팀이 빠짐없이 연합팀 3개로 편성되어야 시작할 수 있다.
- 조를 넘는 편성, 중복 편성, 미배정 팀, 연합팀별 구성팀 수 오류가 있으면 편성 미완료로 표시한다.
- 경기 시작 뒤 팀 편성과 규칙을 잠근다. 출전 선수 교체는 시도 시작 전에만 허용하고 변경 이력을 남긴다.

## 운영 순서

1. 이벤트 생성 및 A/B 각 조의 참가팀 6개 지정.
2. 각 조 안에서 두 팀씩 묶기 → 연합팀 6개 이름 입력 → 전체 편성 공개.
3. 종목별 출전 선수 등록 및 규칙 확인.
4. 슈팅 게임 진행 → 6개 연합팀 기록 검토 → 전체 종목 순위·승점 확정 → 종합 순위 갱신.
5. 공 살리기 진행 → 6개 연합팀 기록 검토 → 전체 종목 순위·승점 확정 → 두 종목 승점 합산.
6. 두 종목 각각의 기록 동률을 해소해 1~6위를 확정한 뒤 합산 점수 계산. 정상 순위를 확정한 팀들의 합산점수는 서로 다르며 공 살리기 순위대로 최종 순위가 결정된다.
7. 우승 후보 계산 → 운영자의 최종 확정 및 우승 화면 공개. 별도 세 번째 이벤트는 기본 운영에 포함하지 않는다.

## 종합 승점과 동점 처리

속도와 초 또는 횟수를 직접 더하지 않는다. 두 종목의 기록을 각각 순위 승점으로 환산하고 공 살리기에 열 배의 비중을 둔다.

- 사용자 지정 최고점은 슈팅 100점, 공 살리기 1,000점이다. 하위 순위는 기존 비율을 유지해 슈팅 20점 간격, 공 살리기 200점 간격으로 반영한다.

| 종목 순위 | 슈팅 점수 | 공 살리기 점수 |
| --------- | --------- | -------------- |
| 1위       | 100       | 1,000          |
| 2위       | 80        | 800            |
| 3위       | 60        | 600            |
| 4위       | 40        | 400            |
| 5위       | 20        | 200            |
| 6위       | 0         | 0              |

- 공식: `최종 점수 = 슈팅 점수 + 공 살리기 점수`. 위 배점표를 적용하면 `(6 - 슈팅 순위) × 20 + (6 - 공 살리기 순위) × 200`이다.
- 공 살리기 한 순위 차이 200점이 슈팅에서 벌어질 수 있는 최대 차이 100점보다 크다. 따라서 공 살리기의 단독 순위가 확정되면 합산 동점이 없고 최종 순위도 공 살리기 순위와 같다. 슈팅은 보너스 점수와 개인 슈팅왕 시상에 의미가 있으며 종합 순위를 뒤집지는 못한다.
- 예: 공 살리기 1위·슈팅 6위는 1,000점, 공 살리기 2위·슈팅 1위는 900점이다. 슈팅 성적과 관계없이 공 살리기 단독 1위가 최종 우승한다.
- 위 성질은 정상 단독 순위에 따른 배점에 적용된다. 실제 측정 기록의 동률, 기권, 실격은 별도 판정해야 하며 미확정 상태를 단독 순위처럼 취급하지 않는다.
- 종목 순위와 기록 동률 처리 기준을 행사 전에 확정한다. 공동 순위·평균 승점·숨겨진 소수점 또는 임의 가산점으로 표시 점수를 바꾸지 않는다.
- 실제 기록의 동률은 종목별로 먼저 해소한다. 슈팅은 두 대표의 최고 속도 평균 → 이번 종목의 유효 속도 전체를 높은 순으로 정렬해 차례로 비교한다. 공 살리기는 두 시도 중 최고 기록 → 나머지 시도 기록 순으로 비교한다. 두 종목 모두 모든 팀의 정해진 시도 기회를 완료하거나 공식 처리한 뒤 판정한다.
- 유효한 보조 기록이 없는 경우 유효한 보조 기록이 있는 팀보다 뒤로 판정하며, 보조 기록이 모두 없거나 비교할 기록까지 같으면 공식 동률 판정을 진행한다.
- 기록 비교로도 동일하면 동점 팀끼리 해당 종목을 재도전해 순위를 확정하는 방식을 추천한다. 공 살리기는 본게임의 연장으로 진행하며 동일 조건의 추가 도전 기록을 비교하고, 계속 동률인 팀은 재도전한다. 추가 기록은 동률 해소용으로 분리해 저장한다. 시스템이 팀 ID나 등록 순서로 단독 순위를 선택하지 않는다.
- 기록 동률 처리 방식은 행사 시작 전에 확인·고정한다. 판정 전에는 `순위 확정 대기`를 표시하고 해당 종목 점수 및 최종 우승 확정을 막는다.
- 미진행, 측정 실패, 무효 기록을 유효한 0 기록으로 바꾸지 않는다. 결과 확정 전 미해결로 남겨 재시도 여부를 판정한다.
- 공식 기권·실격은 그 종목 0점으로 별도 처리한다. 대회 실격 또는 두 종목 모두 기권한 팀은 우승 대상에서 제외한다. 이러한 상태는 정상 1~6위와 구분하며 측정 실패를 자동 기권으로 처리하지 않는다.
- 모든 연합팀의 두 종목 결과가 확정되어야 최종 우승 판정이 가능하다. 진행 중에는 임시 순위로 표시한다.
- 중계에서 두 연합팀을 한 쌍으로 비교하는 것은 현장 진행을 위한 조합이다. 종목별 승점은 모든 6개 연합팀의 기록을 비교해 계산하며, 상대와의 1대1 승패나 탈락전으로 계산하지 않는다.

배점 적용 예시. 팀명과 기록 순위는 설명을 위한 가상 값이다.

| 종합 순위 | 연합팀            | 슈팅  | 공 살리기 | 합계    |
| --------- | ----------------- | ----- | --------- | ------- |
| 1         | 파도연합 · B연합1 | 40점  | 1,000점   | 1,040점 |
| 2         | 태풍연합 · B연합2 | 20점  | 800점     | 820점   |
| 3         | 번개연합 · A연합1 | 100점 | 600점     | 700점   |
| 4         | 돌풍연합 · B연합3 | 0점   | 400점     | 400점   |
| 5         | 불꽃연합 · A연합2 | 80점  | 200점     | 280점   |
| 6         | 질주연합 · A연합3 | 60점  | 0점       | 60점    |

위 예시에서는 파도연합이 1,040점으로 우승한다. 슈팅 100점·공 살리기 1,000점의 비중을 적용한 가상 결과이며, 실제 우승은 전체 기록 확정 후 계산한다.

## 중계 화면

공통 흐름: `준비 → 진행/측정 → 기록 공개 → 현재 두 연합팀 비교 → 필요 시 종목 기록 동률 판정 → 6개 연합팀 종목 순위 확정 → 두 종목 합산 순위 → 우승 발표`.

### 슈팅

- 현재 선수 이름, 연합팀명, 시도 차례 표시.
- 속도 입력 중에는 값이 송출되지 않는다. 저장이 확인된 기록을 운영자가 공개한다.
- 공개 후 약 4초 동안 속도를 크게 표시하고 양 팀 비교 화면으로 자동 전환한다.
- 이번 시도, 개인 최고, 팀 종목 기록을 구분한다. 상대 미시도는 `도전 대기`로 표시한다.
- 다음 선수로 넘어가는 동작은 운영자가 실행한다.
- 비교할 두 연합팀과 출전 순서는 별도로 설정한다. 모든 연합팀에 같은 시도 기회를 보장한다.

### 공 살리기

- 현재 연합팀과 출전 6명을 표시한다.
- 시간 방식: 공식 시작·종료 기준을 사전 확정한 뒤 운영자가 시작/종료를 누르거나 외부 측정값을 입력한다.
- 횟수 방식: 판정자가 셈한 기록을 입력한다. 필요하면 +1/-1 조작을 제공하되 기록 확정 전 검토한다.
- 바닥 접촉, 원 경계 이탈, 손 사용, 시작 터치와 종료 터치의 인정 여부는 행사 규칙으로 사전 확정하고 판정자가 적용한다.
- 기록 공개 → 상대 기록 비교 → 모든 팀 결과 확정 순서로 진행한다.

### 공통 제어

- 자동 전환 잠시 멈춤, 비교 화면 바로 보기, 기록 다시 공개, 중계 미리보기.
- 전체 화면 전광판과 OBS 투명 배경 송출이 동일한 상태를 사용한다.
- 수정 중인 값과 내부 메모는 송출하지 않는다. 공개용 데이터에는 필요한 팀명·선수명·기록만 포함한다.
- 최종 우승 화면에 연합팀명과 원 구성팀 두 개를 함께 표시한다.
- 전체 순위 화면에 6개 연합팀의 새 팀명, 원 소속조, 슈팅 순위·승점, 공 살리기 순위·승점, 합계, 최종 순위를 표시한다. 미확정 기록은 확정 승점과 구분한다.
- 본게임 기록 동률로 재도전 중이면 `본게임 연장 · 순위 결정전`을 표시하고 최종 우승 발표를 대기한다.

## 구현 모듈과 저장 구조

기능 폴더: `src/features/alliance-event/`. 아래는 책임별 설계 구분이며 실제 파일 배치는 기능 README에 정리했다.

| 모듈              | 책임                                                          |
| ----------------- | ------------------------------------------------------------- |
| `teams/`          | 원 구성팀 연결, 연합팀 이름, 출전 명단                        |
| `games/shooting/` | 슈팅 차례, 시도별 속도, 개인·팀 기록 계산                     |
| `games/keep-up/`  | 6인 공 살리기, 시간·횟수 기록                                 |
| `scoring/`        | 6개 연합팀 종목 순위, 동점 승점, 합산 순위, 동점 및 우승 판정 |
| `control/`        | 운영 화면, 기록 검토·확정, 수정·무효 처리                     |
| `broadcast/`      | 기록 연출, 양 팀 비교, 종합 순위, 우승 화면                   |
| `data/`           | 영속 저장, 실시간 동기화, 재접속 복원                         |

독립 저장 대상: 이벤트와 잠근 규칙, 연합팀과 구성팀, 종목별 출전자, 시도별 원기록, 확정 결과, 우승 결정 기록, 현재 송출 상태.

기존 선수별 `skill_challenge_records`는 참가자 중심 기록이므로 여러 연합팀·여러 시도·종합 우승의 원장으로 사용하지 않는다. 기존 로그인 및 선수 조회를 재사용하고 새 이벤트 도메인을 분리한다. 기존 개인 속도 계산에는 130km/h 상한 보정이 있으므로 새 종목에서 이를 그대로 재사용하지 않는다. 측정 범위 밖 입력은 설명과 함께 검토하고 원기록을 조용히 바꾸지 않는다.

서버에서 권한, 출전 소속, 시도 중복, 확정 상태를 검사한다. 기록 확정과 결과 갱신을 일관되게 처리하고 요청 식별자로 중복 저장을 방지한다. 송출 상태에 현재 단계·공개 기록·서버 기준 전환 시각·버전을 저장해 새로고침과 재접속 후 복원한다. 기록 수정 시 종합 순위와 우승 판정을 다시 계산하고 이전 확정 결과가 그대로 남지 않도록 무효화한다.

## 구현 검증 기준

- A조 6개 원 참가팀이 연합팀 3개로, B조 6개 원 참가팀이 연합팀 3개로 편성되며 기존 선수 소속은 유지된다.
- 두 조를 섞은 연합팀 편성 및 12개 원 참가팀 중 중복·누락된 편성을 거부한다.
- 구성팀과 출전 선수의 중복 및 잘못된 소속이 거부된다.
- 슈팅 대표가 남자 1명·여자 1명인지 검사하고 두 선수의 개인 최고 기록을 모두 팀 기록에 반영한다.
- 슈팅 교대와 시도 횟수가 일치하고 공개 전 숫자가 송출되지 않는다.
- 기록 공개 뒤 정해진 시점에 비교 화면으로 전환하며 수동 유지 기능이 동작한다.
- 공 살리기는 확정된 시간/횟수 기준과 동일한 기회를 적용한다.
- 종목 기록 동률, 미진행, 무효, 기권을 구분하고 승점을 올바르게 계산한다.
- 양 조 전체 6개 연합팀의 종목 순위로 승점을 산정하고 두 종목 합계로 최종 순위를 계산한다.
- 두 종목 결과가 모두 확정되기 전에 단독 우승을 확정하지 않는다.
- 종목 기록 동률 시 보조 기록과 사전에 정한 공식 판정 절차로 단독 순위를 결정하고, 판정이 남아 있으면 해당 종목 및 우승 확정을 막는다.
- 슈팅 1위 100점·공 살리기 1위 1,000점이며 합산 최고점은 1,100점이다. 각 순위의 공 살리기 배점은 슈팅의 열 배다.
- 정상 단독 순위 6×6 조합의 합계가 모두 다르고, 서로 다른 공 살리기 순위의 합계 구간이 겹치지 않는다. 공 살리기 단독 1위는 슈팅 결과와 관계없이 최종 우승한다.
- 실제 기록 동률은 사전 규칙과 필요한 재도전으로 해소하며, 판정 전에는 최종 우승을 발표하지 않는다.
- 정상 6위의 0점과 미진행·기권·실격 상태를 구분한다.
- 중복 클릭·동시 조작·새로고침·재접속으로 시도나 승점이 중복되지 않는다.
- 확정 결과 수정 시 영향을 받는 종합 순위와 우승 상태가 갱신된다.
- 실제 송출 장비에서 리허설하고 연결 중단·복구를 확인한다.
