# 컵 대회 운영팀 가이드

공유 주소: https://fairground-kor.com/cup-ops

2026년 10월 3일 첫 번째 컵 대회의 운영 자료입니다. 기존 독립 가이드를 공식 도메인으로 옮겼으며, 별도 로그인 없이 링크로 확인합니다. 검색 결과에서는 제외합니다.

## 수정 위치

- `public/cup-ops/data.js`: 시간표, 대진, 담당자, 제품별 릴스 촬영 컷리스트·즉석 이벤트 배정량, 준비 일정, 승급 기준
- `public/cup-ops/team-seeds.js`: 확정 조별 시드와 팀명. 대진·휴식 팀 표시는 이 매핑을 함께 사용한다.
- `public/cup-ops/app.js`: 안내 섹션 렌더링, 목차, 링크 공유
- `public/cup-ops/index.html`: 행사 개요와 공유 메타데이터
- `public/cup-ops/styles.css`: 공통 화면과 모바일 배치
- `public/cup-ops/tiers.css`: 선수카드 프레임과 선수 이미지 위치
- `public/cup-ops/assets/`: 로고, 글꼴, 카드·선수·협찬사 이미지
- `next.config.ts`: `/cup-ops`를 정적 HTML로 연결
- `next-sitemap.config.js`: 검색 제외 경로

스타일·스크립트·이미지 주소는 `/cup-ops/` 기준입니다. 카드 이미지 경로를 수정할 때도 이 접두사를 유지합니다. CSS의 이미지·글꼴 상대 경로와 JavaScript의 모듈 import는 파일 위치를 기준으로 해석됩니다.

다른 서비스 화면과 스타일이 섞이지 않도록 가이드 파일은 이 폴더 안에서 관리합니다. 공유 버튼은 현재 공식 도메인의 주소와 선택한 섹션을 복사합니다. DB나 회원 데이터에 연결하지 않습니다.

## 2026-10-03 현장 확정 일정

운영 DB의 현장 변경을 `public/cup-ops/event-schedule.js`에서 기본 시간표에 적용한다. 1~4경기의 기존 대진과 14:00 이후 순위결정전 일정은 유지한다. 5경기는 11:15에 시작하고, 이후 20분 간격으로 진행한다. 순서는 ROOT FC B팀–데카트론 관심점, FC LEGACY–FC 수박, 데카트론 사랑점–ROOT FC A팀, BOB FS–FC흰둥이, ROOT FC B팀–FC 수박, FC LEGACY–데카트론 관심점, 데카트론 사랑점–FC흰둥이, BOB FS–ROOT FC A팀이다. 출전팀 집합은 경기 시작 5분 전이며, 5경기는 11:10이다.

가이드의 1~4경기 시각은 당초 계획이며, 이미 진행한 경기는 현장 실제 기록을 따른다. 5~12경기는 현장 확정 시간표를 우선한다. 앞서 검토한 추가 20분 휴식은 11:15 시작 요청으로 변경되어 이 시간표에 포함하지 않는다. 촬영·MC 이벤트의 별도 시각은 이 경기 순서 변경으로 자동 이동시키지 않는다.

## 확정 경기 일정

2026년 10월 3일 대회는 A구장 한 면에서 진행한다. 조별 12경기는 10:00–14:00, 순위결정전 8경기는 14:00–16:40다. 실내구장은 챌린지 공간이다. 경기 12분 + 교대 3분 + 장비 점검·준비 5분을 합쳐 20분 간격으로 진행하며 별도 점심 슬롯은 없다. 두 출전팀 모두 자기 경기 시작 5분 전까지 A구장 앞에 집합하며, 첫 경기 집합은 09:55다. 경기별 집합 시각은 `match-report-time.js`에서 계산한다. 시상은 16:40–17:05, 단체사진은 17:05–17:10이다. 실내 챌린지는 16:00에 마무리하고 대관 종료 18:00 전까지 정리한다.

관리자 자동 편성과 큐시트는 `src/lib/group-fixture-timetable.ts`의 기본 단일 구장 순서를 사용한다. `tests/single-court-fixtures.test.ts`는 기본 시간표와 자동 편성의 일치를 검증하고, 현장 변경 시간표를 별도로 검증한다. 이미 저장된 대진을 현장에서 바꿀 때는 운영 DB와 `event-schedule.js`의 순서·시각을 함께 갱신한다. 가이드의 순위결정전 출전팀은 조별 순위와 준결승 결과가 확정된 뒤 결정한다.
