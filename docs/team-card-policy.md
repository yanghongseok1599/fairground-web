# 팀 카드 표시 기준

- 사용자 확정 기준(2026-09-29): **우승팀은 플래티넘으로 승급한다.** 별도 테두리·광채·반짝임을 추가하는 방식이 아니다.
- 저장된 `league_tier = premium`을 플래티넘 카드 프레임으로 표시한다. 현재 순위 1위, 동률 정렬 순서, 연습 결과만으로 우승을 추정하지 않는다.
- 우승팀 확정/등급 저장과 카드 렌더링은 분리한다. 확정하지 않은 팀을 임의 승급하지 않는다.
- BOB FS의 어두운 팀 카드에서는 원본 로고의 검정 잉크를 흰색으로 표시한다. 노란색·파란색 포인트, 모양, 투명도, 배치는 보존한다. 밝은 바탕에 표시하는 엠블럼은 원본을 사용한다.
- 카드 색상 처리는 `src/lib/team-card-logo.ts`, 카드 합성은 `src/lib/team-card-canvas.ts`에서 공유한다. 홈·팀 목록·팀 상세에 별도 렌더링 규칙을 만들지 않는다.
