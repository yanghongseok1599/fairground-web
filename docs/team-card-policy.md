# 팀 카드 표시 기준

- 사용자 확정 디자인(2026-10-09): 월계수와 금속 장식의 **클럽 헤리티지 2안**을 모든 팀에 적용한다. 브론즈·실버·골드는 원본 금속 프레임을 유지하고, **플래티넘에만 테두리와 보석의 아이스블루·화이트 반짝임**을 포함한다. 반짝임은 승인된 프레임 이미지 안에만 존재하며 CSS나 캔버스에서 추가하지 않는다. 이전의 전체 등급 반짝임 금지 기준은 이 승인 범위에서 갱신한다.
- 확정 대회 결과의 `finalCardTiers[team.id]`를 우선하고, 결과가 없는 팀은 저장된 `team.leagueTier`를 사용한다. `premium`은 플래티넘 카드다. 현재 순위 1위, 동률 정렬 순서, 연습 결과만으로 우승을 추정하지 않는다.
- 최종 순위는 기존 `final-card-tier-store`의 공용 Realtime·보완 조회로 읽는다. 철회 팀 제외 및 최신 대회 우선 정책을 그대로 사용하고, 조회 실패 시 이전에 확인한 등급을 유지한다. 홈페이지·팀 목록·팀 상세가 같은 저장소를 구독한다.
- 카드 등급은 표시 전용이며 DB 리그 등급을 변경하지 않는다. 팀 상세의 `브론즈 리그` 등 기존 리그 표시는 유지하고 `카드 등급 · 플래티넘` 등을 별도로 표시한다. 확정하지 않은 팀을 임의 승급하지 않는다.
- BOB FS의 어두운 팀 카드에서는 원본 로고의 검정 잉크를 흰색으로 표시한다. 노란색·파란색 포인트, 모양, 투명도, 배치는 보존한다. 밝은 바탕에 표시하는 엠블럼은 원본을 사용한다.
- 프레임 경로·등급 라벨·색상·합성 좌표는 `src/lib/team-card-appearance.ts`에서 공유한다. 기본 출력은 투명 배경의 **1024×1536**이며, 프레임은 `public/images/team-cards/heritage-v1/`의 네 WebP를 사용한다. 긴 팀명은 이름판 너비에 맞춰 축소하며 이름을 줄이거나 생략하지 않는다.
- 카드 색상 처리는 `src/lib/team-card-logo.ts`, 카드 합성은 `src/lib/team-card-canvas.ts`에서 공유한다. 홈·팀 목록·팀 상세·PNG 내보내기에 별도 렌더링 규칙을 만들지 않는다. 플래티넘의 예전 emerald 확대·세로 위치 보정은 새 프레임에 적용하지 않는다.
