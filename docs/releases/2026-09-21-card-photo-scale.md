# 선수카드 사진 크기 조절 UI

## 변경

기존에는 사진 크기를 카드 위 드래그나 휠로만 바꿀 수 있었고, 새 사진을 고르지 않으면 일부 설정 화면에 조절 안내가 나타나지 않았다. 카드 미리보기 바로 아래에 **카드 사진 크기** 컨트롤을 추가했다.

- 50–250% 슬라이더와 현재 비율 표시.
- 10%p 단위 확대·축소 버튼, 기본 크기(92%) 복귀.
- 키보드 조절과 44×44px 확대·축소 버튼.
- 신규 선수카드 설정과 기존 카드 수정에서 같은 컴포넌트를 사용한다.
- 기본 이미지에도 조절할 수 있으며, 실제 카드 미리보기·저장·공유 렌더링은 기존 `photoScale` 경로를 사용한다.

공통 UI는 `src/features/player-card/components/photo-scale-control.tsx`에 분리했다. 기존 사진 파일이나 DB 스키마를 변경하지 않는다. 변경한 크기는 기존 저장 버튼을 눌러 저장한다.

구현 커밋: `9941da8`.

## 검증

- `npm run lint`: 오류 0, 기존 경고 18.
- `npx tsc --noEmit`, `npm run build` 통과.
- 기존 선수카드 프레임·사진 폴백·자산·얼굴 기하 테스트, 상반신 표시 테스트 통과.
- 카드 수정·저장 복구 테스트 10개 통과.
- 실제 운영 소스를 복원하고 이번 3개 파일 변경만 적용한 폴더에서 TypeScript와 대상 ESLint 통과.
- 해당 소스를 개발 Supabase에 연결해 합성 계정으로 브라우저 검증했다. 92→102% 확대, 50/250% 경계 버튼 비활성화, 92% 초기화, 키보드로 150% 설정을 확인했다.
- 150% 저장 후 새로 진입한 카드 수정 화면과 개발 DB `photo_scale=1.5`가 일치했다. 검증에 사용한 합성 계정의 등번호·표시 크기는 원래 값으로 복구했다. 테스트용 초상권 동의는 개발 합성 계정에서만 수행했다.
- 신규 카드 설정의 네 가지 등급 미리보기도 모두 `scale(1.5)`로 반영됐다.
- CSS viewport 390px에서 컨트롤은 좌표 20–355px 안에 배치됐고 가로 넘침이 없었다. 확대·축소 버튼은 각각 44×44px였다. 브라우저 스크린샷 캡처는 도구 timeout으로 실패하여 이미지 기반 시각 검수는 완료하지 못했으며, DOM 크기·조작·저장 동작으로 확인했다.
