# 전체화면 경기장 대기석·종료 확인 수정 — 2026-09-20

전체화면에서 중복 표시되던 ‘원래 화면’ 버튼 두 개를 제거하고 우측 상단 닫기 아이콘 하나로 통합했다. 대기 선수와 전광판은 잔디 밖 상단 영역에 배치해 골키퍼·출전 선수와 겹치지 않는다. 대기 인원이 많으면 각 팀 대기석 안에서 가로로 스크롤한다.

## 배포 범위와 환경

직전 운영 소스 913개를 SHA-1으로 검증해 시스템 임시 폴더에 복원하고 이번 구현 커밋의 2개 소스만 패치했다. 업로드된 914개 파일 전체가 검증본과 일치하며, 직전 운영본과의 차이는 해당 2개와 타입 검사 생성물 `tsconfig.tsbuildinfo`다. [배포 명세](2026-09-20-match-court-controls-manifest.json)를 참고한다. 작업 브랜치의 다른 기능과 미완료 사용자 변경은 포함하지 않았다.

환경 분리 안전장치와 마이그레이션 이력을 읽기 전용으로 확인했다. 기존 이력 불일치는 남아 있다. DB·Auth·Storage·Realtime 전송 로직·마이그레이션·지속 환경변수는 변경하지 않았다. 사용자 공동 테스트방은 조작하지 않고 별도의 탭 내 연습 경기로 검증했다.

새 DB 참조는 없다. 배포본의 참조 150개를 2026-09-15 운영 카탈로그와 대조해 누락 0개를 확인했다. 새 카탈로그 조회는 수행하지 않았다. 기존 Production의 `SUPABASE_DB_URL` 미설정 때문에 이번 빌드에만 `FAIRGROUND_SKIP_DB_PARITY=1`을 전달했으며 게이트 코드나 지속 환경변수를 바꾸지 않았다. 원격 설치에서 기존 의존성 감사 경고 5건이 남아 있고 의존성은 변경하지 않았다.
