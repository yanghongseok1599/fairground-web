## 원인과 변경 범위

앞서 전달한 검인 주소는 개발 Supabase를 사용하는 Preview였고 `ccv5`는 운영에만 존재했다. 운영 계정은 승인된 관리자이며 이메일 인증·비밀번호 등록 상태가 정상이고 15:35 KST 로그인 성공 기록이 있었다. 운영 `/admin/inspections`는 404였다. 계정 암호 오류나 Supabase 서버 장애로 해결할 상황이 아니라 검인 기능의 운영 배포가 빠진 상태였다.

기존 관리자 계정을 그대로 사용할 수 있도록 검인 기능을 운영에 반영했다. 관리자 메뉴의 현장 선수검인과 참가자 마이페이지의 검인 완료 표시를 포함한다. 비밀번호·OAuth·회원 권한을 변경하거나 운영 계정을 개발로 복제하지 않았다.
