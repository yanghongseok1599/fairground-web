# 홈페이지 메인 영상 무음 자동재생

사용자가 제공한 `/Users/seok/Desktop/가로 메인.mp4`를 홈페이지 첫 화면의 16:9 영상으로 적용했다. 기존 스크롤 재생·문구 오버레이를 교체하고 접근성용 페이지 제목은 유지한다. 구현은 `src/components/home-video-hero.tsx`와 `src/app/page.tsx`에 나누었다.

## 영상 자산

| 자산 | 규격 | 용량 |
|---|---|---:|
| 데스크톱 MP4 | 1920×1080 | 18,299,993 bytes |
| 모바일 MP4 | 960×540 | 9,698,986 bytes |
| 데스크톱 WebP | 1280×720 | 167,552 bytes |
| 모바일 WebP | 640×360 | 59,950 bytes |

`public/videos/fairground-home-main-20261008` 접두사의 네 파일을 사용한다. MP4는 H.264, 30fps, 79.166667초, 2,375프레임, 오디오 트랙 0개이며 faststart를 적용했다. 원본 152,796,194 bytes는 보존했고 장면·색상·화면 비율을 바꾸지 않았다. 원본 60fps를 30fps로 최적화하면서 생긴 길이 반올림은 약 0.017초다. 자산 해시·전체 디코딩·시각 검수 결과는 [최적화 보고서](2026-10-08-home-hero-video/optimization-report.json)에 기록했다.

## 재생 동작

화면에 보이면 무음 자동재생·반복·인라인 재생을 시작한다. 스크롤로 화면을 벗어나거나 탭을 숨기면 일시정지한다. 재생 버튼으로 선택한 일시정지는 스크롤 후에도 유지된다. 모션 감소·데이터 절약·느린 네트워크에서는 포스터를 먼저 표시하고 자동 영상 요청을 미루며, 사용자가 재생을 선택하면 시작한다. 모바일도 원본 가로 구도를 유지하며 작은 전용 파일을 사용한다.

홈 비디오 구성 검토에 [Lazyweb 실제 사례 검색](https://www.lazyweb.com/agentic-search/648211d8-7e52-4297-8055-5af3b5aeff73)을 사용했다.

## 검증

기준 소스는 `db8d6c7`이며 퀴즈·DB 타입·헤더의 진행 중인 변경을 제외한 격리 worktree에서 검증했다.

- `npm ci`: 잠금 파일 유지.
- `npm run lint`: 오류 0개, 기존 경고 16개.
- `npx tsc --noEmit`: 통과.
- Supabase 환경 분리 4개 테스트·스키마 검사 도구 21개 테스트: 통과.
- 실제 개발·운영 DB 읽기 전용 카탈로그 대조: 각각 448개 소스 파일, 함수 44개·릴레이션 28개·버킷 1개, 누락/동적/제외 항목 0개.
- 실제 데스크톱·모바일 브라우저: 영상 재생 시간 증가, 무음/반복/인라인, 수동 정지·재개, 스크롤·탭 비활성 정지, 모션 감소 시 MP4 요청 없음 및 수동 재생 확인.
- 운영 `vercel build --prod`: 통과. 타입 계약 370개·조회 103개를 실제 운영 DB와 대조한 뒤 Next 빌드·54개 정적 페이지·배포 출력을 생성했다. `npm run build`의 운영 DB 게이트를 실행하며 우회하지 않는다.

이번 변경은 DB·마이그레이션·환경변수·권한을 바꾸지 않는다. 기존 잠금 파일의 npm audit 결과(high 12개, critical 1개)는 별도 유지보수 대상으로 기록하고 의존성을 변경하지 않았다. 푸시 후 자동 Preview의 최종 Ready 상태를 확인한 뒤, 검증된 Production 빌드를 배포하고 공식 도메인·영상·포스터 응답을 확인한다.
