# 모바일 경기 기록 상태 바 정리

모바일에서 상단 기록·백업 바를 숨겨 달라는 요청을 반영했다. 경기 운영 화면과 전체화면 기록이 함께 사용하는 `RecordingStatus`에만 표시 조건을 추가했다.

- 기존 모바일 기준인 화면 폭 768px 미만에서는 정상 동기화 바와 기록 백업 버튼을 숨긴다. 데스크톱 관리자의 백업 기능은 유지한다.
- 미전송 기록, 저장 오류, 공유 연결 끊김, 다른 기기의 전송 대기, 종료 복구 안내는 모바일에도 표시한다.
- 모바일에서 숨긴 백업 버튼을 누르도록 안내하던 관리자 오류 문구를 연결·기기 저장 상태 확인 안내로 바꿨다.
- IndexedDB, 기록 대기열, 자동 저장·재전송, 경기 제어 및 서버 요청은 변경하지 않았다. 운영·개발 DB 쓰기는 수행하지 않았다.

## 검증

- 경기 진입·전체화면·종료 복구 및 Supabase 안전장치 기존 테스트: 24개 통과.
- TypeScript 통과, lint 오류 0개(기존 경고 16개).
- 개발 및 운영 실제 카탈로그 정합성: 타입 계약 366개·조회 99개 통과.
- 운영 환경의 `vercel build --prod` 완료. 기존 `npm run build` 및 prebuild 정합성 검사를 그대로 실행했다.
- 정상 상태에서만 모바일 숨김이 적용되는 조건과 저장 동작 미변경을 별도 읽기 전용 리뷰로 확인했다.
- 배포 ID·최종 상태·운영 화면 확인 결과는 프로젝트 바깥의 `output/ops/2026-10-03-mobile-recording-status`에 보관한다. 운영 경기 쓰기를 동반한 테스트는 하지 않는다.

UI 참고: [Lazyweb 모바일 동기화 안내](https://www.lazyweb.com/agentic-search/0ad70bf6-5916-4fa1-9ece-39f6f6b84c2a). 동기화 보조 영역을 참고했으며 화면 구성은 기존 FairGround 구조와 사용자의 숨김 요청을 따른다.
