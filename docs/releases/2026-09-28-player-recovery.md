## 별도로 남은 종료 집계 DB 오류

운영 스키마 복제본에서 기존 `end_match`가 bigint 집계 결과를 integer 인자의 `compute_card_rating`에 전달하여 실패하는 것을 재현했다. 현재 운영 함수 정의도 대조했다. 기존 준비 SQL `20260928010000_match_finalization_regression_fix.sql`을 **격리 로컬 DB에만** 적용하면 종료·취소·MOM·순위·중복 종료·롤백 검수 10개가 통과한다.

운영에는 진행 중 상태의 경기 1건이 남아 있어 이 SQL을 적용하지 않았다. 사용자에게 실제 진행 중인지 확인을 요청했다. 이 항목이 해결되기 전에는 실전 종료/최종 확정까지 정상이라고 보장하지 않는다. 운영 DB 변경·회원 데이터 덮어쓰기·마이그레이션 이력 수정은 이번 복구에서 수행하지 않았다.
