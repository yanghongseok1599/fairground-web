# 카카오 대회 도구 1차

대회 상세에 대회 공유와 경기장 검색을 추가하고, 종료 경기마다 점수·팀명·대회명·라운드를 공유한다. 공유 링크는 공식 도메인의 경기 앵커로 연결한다. 비공개 예정 대진은 메시지에 포함하지 않는다.

기존 선수 카드 공유의 SDK 로더를 공통 모듈로 분리했다. 로딩 시간 초과와 네트워크 오류 후 재시도를 지원하며, 새 공유 버튼은 오류 시 사용자에게 링크 복사 선택지를 제공한다. 키가 없는 환경은 기기 공유/복사를 사용한다.

공식 채널 주소 확인 대기: NEXT_PUBLIC_KAKAO_CHANNEL_URL 설정 시 문의 버튼이 표시된다. 카카오 콘솔·DB·운영 웹은 변경하지 않았다.

검증: TypeScript 통과, 전체 lint 오류 0(기존 경고), 변경 파일 lint 통과, 링크/공유/기존 선수 카드 링크 테스트 통과. npm run build는 SUPABASE_DB_URL 미설정으로 prebuild 스키마 게이트에서 차단되어 빌드·배포 미완료다. 게이트를 우회하지 않았다. 실제 기기의 카카오톡 발송과 모바일 화면 검수는 남아 있다.

디스크: 프로젝트 약 2.5GB. 기존 node_modules 약 751MB, public 약 862MB, 기존 PPTX 작업 폴더 약 132MB가 있으며 이번 작업에서 생성한 브라우저 프로파일이나 렌더 캐시는 없다. 기존 사용자 작업 파일은 보존했다.
