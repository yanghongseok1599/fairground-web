# 페스티벌 설문 결과 관리

승인 관리자는 운영 콘솔의 **설문 결과**(`/admin/survey`)에서 익명 응답을 확인한다. 전체·주장·선수 필터를 요약, 문항별 분포, 자유 의견, 개별 12문항 응답과 CSV에 함께 적용한다. 추천 NPS와 재참가 의향의 계산 기준을 표시하며 응답이 없으면 평균·비율을 0으로 오인하지 않게 비워 둔다.

결과 기능은 `src/features/festival-survey/results/`의 모델·조회·상태·CSV·화면 모듈로 나눴다. 조회 RPC `get_festival_survey_results()`는 현재 로그인 회원의 `profiles.role='admin'`과 `is_approved=true`를 DB에서 확인한다. 미승인 관리자·선수·심판·검인 담당·익명은 조회할 수 없다. 단일 JSON 값으로 전체 응답을 반환해 PostgREST 행 제한으로 통계가 잘리지 않게 했다. CSV는 한국어 UTF-8 BOM과 수식 실행 방지를 적용하며 회원 정보와 응답 UUID를 포함하지 않는다.

## DB 반영과 보존

`20261008020000_festival_survey_results.sql` 동일 SHA256 `83b4e9caa20ba9c19fbab56653c1e1586b518fff9d9392124caf2a423f3681e6`를 개발·운영에 각각 반영했다. 새 읽기 전용 함수 한 개만 추가하고 기존 응답 테이블, 제출 함수, 직접 테이블 권한과 RLS를 유지했다.

격리 PG17 복원본에서 1,001개 합성 익명 응답의 전체 조회와 관리자 승인 회수 직후 거절을 검증했다. 다른 역할의 조회와 관리자의 직접 테이블 조회·수정·삭제를 거절하며, 모든 합성 사용자·응답은 트랜잭션 롤백으로 제거했다. pg_dump가 생략하는 명시적 소유자 전용 기본 권한은 shadow에만 그대로 재현하고 카탈로그 완전 일치를 검증했다.

실제 개발·운영 DB에서도 기존 승인 관리자 역할의 RPC 조회와 익명·일반 회원 거절을 확인했다. 응답 원문을 도구 출력에 남기거나 운영에 합성 응답을 추가하지 않았다. 반영 전후 행 해시는 같은 serializable 트랜잭션 snapshot에서 비교해 새 참가자 응답이 동시에 들어오는 것을 허용한다. 기존 이력은 그대로 보존하고 이 버전 하나만 추가했다. linked push/reset/repair는 실행하지 않았다.

백업·정의 diff·격리 검수·적용 영수증은 저장소 밖 `../output/ops/2026-10-08-festival-survey-results/{development,production}/`에 제한 권한으로 보관한다. `scripts/survey/task-config.mjs`에 작업별 마이그레이션·검수·허용 객체를 분리했다. `verify-migration.mjs --task results`는 원격 읽기와 격리 리허설만 수행하고, `apply-migration.mjs --task results`는 기본 롤백 모드이며 검증된 SQL의 명시적 `--apply`에서만 반영한다. 운영은 별도 `--environment production --linked-credentials`를 요구한다.

## 애플리케이션 검증과 웹 배포 증거

집계 6개·조회 클라이언트 3개·CSV 3개·기존 설문 모델 5개·제출 API 5개·관리자 메뉴와 안전/정합성 회귀 검수가 통과했다. TypeScript와 lint는 오류가 없으며 기존 lint 경고 16개는 이번 변경 범위 밖이다. 실제 배포할 추적 소스만 격리한 정상 `npm run build`가 개발의 타입 컬럼 370개·조회 계약 103개와 실제 함수·릴레이션·버킷 검사를 통과하고 `/admin/survey`를 생성했다. 사용자 미추적 기능을 배포에 포함하거나 정합성 검사를 우회하지 않았다.

개발 관리자 세션에서 합성 응답 6건으로 전체·주장·선수 평균, NPS와 재참가 비율을 확인했다. 390px 모바일과 1440px 데스크톱에서 가로 넘침이 없으며 개별 응답 12문항·그리드 6행을 펼쳐 확인했다. 실제 CSV 다운로드는 읽을 수 있는 한국어 파일명, 선택한 역할 2건, UTF-8 BOM, 줄바꿈·따옴표와 수식 실행 방지를 검증했다. 검수용 UUID 6개와 전용 표식이 모두 일치하는 응답만 개발에서 삭제해 다른 응답과 운영은 보존했다.

권한 오류에는 이미 읽은 응답·통계·CSV를 즉시 제거한다. 계정 전환은 관리자 가드 해제와 사용자 ID별 컴포넌트 키로 이전 조회 결과를 분리한다. 일반 연결 실패는 마지막 조회 시각과 오류를 표시하고 재시도할 수 있다.

운영 화면 주소는 [설문 결과](https://fairground-kor.com/admin/survey)이며 운영 콘솔의 첫 **설문 결과** 메뉴로 들어간다. 자동 Preview와 운영 배포의 소스 커밋·주소·최종 상태·정식 도메인 검수 영수증은 저장소 밖 `../output/ops/2026-10-08-festival-survey-results/web-release.json`에 기록한다. 빌드는 각 대상의 실제 DB 정합성 검사를 유지한다. 스키마 백업과 영수증은 보존하고 임시 의존성·빌드·브라우저 산출물은 작업 후 정리한다.
