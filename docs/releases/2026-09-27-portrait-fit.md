# 선수카드 얼굴·목 연결과 사진 맞춤 — 2026-09-27

구현 커밋: `adcdd18`. 선수 등록과 카드 수정의 얼굴 합성에 같은 처리·미리보기 모듈을 적용했다.

## 변경

- 눈 간격만으로 머리 크기를 정하던 계산을 턱선 너비와 얼굴 높이 기준의 균일 배율로 변경했다. 얼굴을 가로·세로로 다르게 늘리지 않는다.
- 템플릿을 턱 높이에서 수평으로 지우면 목 양옆까지 잘리던 문제를 수정했다. 턱 아래 중앙의 목 피부는 보존하고, 기존 모델의 옆 턱·귀가 남지 않게 제거 범위를 제한했다.
- 얼굴 합성 후 **얼굴 크기·좌우 위치·높이**를 조절하는 공통 창을 추가했다. 유니폼과 어깨는 움직이지 않는다. `이 사진 사용`을 눌러야 편집 중인 카드 사진에 반영되고, 취소하면 기존 사진이 유지된다.
- 사진 인식/분할은 한 번만 수행하고 조절에는 준비된 레이어를 재사용한다. 오래된 미리보기 응답은 무시하며, 현재 조절값의 렌더링이 끝나기 전에는 적용할 수 없다. Blob URL은 교체·닫기 때 해제한다.
- 머리의 실제 불투명 영역을 기준으로 여백을 확보한다. 조절할 때 캔버스 높이가 바뀌어 몸통이 움직이지 않도록 일정하게 유지한다.
- 사진은 기존과 같이 기기 안에서 처리한다. 새로운 외부 이미지 서비스·DB 컬럼·API·의존성은 추가하지 않았다.
