# 페스티벌 만족도 조사 53차 완성

참가자 공개 경로 `/survey`. 제공한 제목·안내와 12문항을 유지하며 로그인 없이 익명 응답을 받는다. 1~10번 및 만족도 여섯 행은 필수, 11~12번은 선택이다. 모바일은 만족도 표를 항목별 선택으로 펼친다. 추천 의향 0점을 정상 답안으로 처리하고, 오류 시 첫 미응답으로 이동한다.

설문 기능을 `src/features/festival-survey/`의 모델·입력·화면·상태·서버 모듈로 분리했다. 공통 회원 서비스·설치 팝업·알림·경기 기록 동기화는 이 경로에서 시작하지 않는다. 이름·회원 ID·팀·IP·사용자 에이전트 대신 무작위 UUID·답변·서버 시각만 저장한다. 일반 API 역할의 응답 조회·수정·삭제·직접 삽입은 차단한다.

전송 전 정규화된 답안과 UUID를 탭 내 sessionStorage에 보관한다. 연결 단절·불확실한 응답·새로고침 뒤에도 같은 답안으로 재전송하고 중복 저장하지 않는다. 성공 영수증 후 초안을 지우고 제출 완료 화면을 유지한다. 익명 참가자를 여러 기기에 걸쳐 식별하는 방식은 사용하지 않는다.
