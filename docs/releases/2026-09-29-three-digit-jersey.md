# 2026-09-29 등번호 숫자 1~3자리 확장

사용자 요청에 따라 `0`, `00`, `000`, `01`, `02`, `007`, `999` 등 숫자 1~3자리를 입력 그대로 저장·표시한다. 글자, 부호, 소수, 빈칸, 4자리 이상은 허용하지 않는다. 기존 미지정 숫자 0과 명시적으로 등록한 0은 계속 구분한다.

- 등록·카드 수정 화면의 최대 길이/안내와 공통 파서·표시·프로필 저장 매퍼를 변경했다. 명단/심판/라인업은 기존 공통 모듈을 통해 새 표기를 사용한다. PNG 파일명도 01과 1, 007과 7을 구분한다.
- 새 컬럼 조회나 생성 없이 `20260929020000_three_digit_jersey_numbers.sql`로 기존 제약조건 2개만 교체했다. 숫자 범위와 문자열-숫자 일치를 DB에서도 검증한다. 기존 함수/뷰/권한/RLS는 그대로다.
- 최신 운영 스키마를 별도 PG17로 복원하여 4,730개 정의(제약조건 포함)를 대조했다. 적용·롤백·재적용과 실제 권한의 합성 DB 검수 7개를 통과한 동일 SQL만 운영에 적용했다.
- 운영 기존 선수 121명을 포함한 31개 테이블 행 해시가 전후 동일했다. 기존 이력 69건을 보존하고 새 버전만 추가했다. DB 재시작, 초기화, 회원/사진/기존 등번호 수정 없음.
- 1~3자리 전체 1,110개 표기 검증, 관련 자동 검수 79개, 출전 자동배치/PNG 검수 6개, 합성 DB 검수 7개 통과. TypeScript·lint(기존 경고 16개, 오류 0개)·실제 운영 DB 대조 게이트·production build 통과.
- 검수 근거와 비공개 DB 백업은 작업공간 `output/ops/2026-09-29-three-digit-jersey`에 보관한다. 로컬 격리 DB에는 실제 회원을 복사하지 않았다.
- 전체 마이그레이션 이력 복구와 hosted 개발 DB 반영은 별개로 미완료 상태다. 운영 linked push/reset/repair 금지 및 실제 DB 대조 게이트를 유지한다.
