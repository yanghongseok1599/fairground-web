# 선수검인 전담 권한 — 2026-09-30

## 결과

전체 관리자 역할과 별개로 선수검인 전담 권한을 추가했다. 기존 선수·감독 역할과 팀 소속을 보존하면서 검인 명단 조회와 완료·취소만 허용한다. 서버는 모든 검인 RPC 요청에서 해당 권한을 재확인한다.

- 검인 담당자에게 운영 콘솔의 검인 메뉴와 헤더의 `선수검인` 진입점을 제공한다.
- 일반 관리자 페이지 가드는 그대로 유지한다. 메뉴 노출만으로 권한을 부여하지 않는다.
- 권한 테이블은 RLS를 켜고 브라우저의 조회·등록·수정·삭제를 모두 차단했다. 본인 권한 조회 RPC는 boolean만 반환한다.
- 요청한 전체 관리자 계정은 이미 승인된 관리자였으며 읽기 전용 검수에서 검인 명단 조회도 통과했다.
- 요청한 검인 전담 이메일은 Auth 사용자·소셜 로그인 연결·프로필에 없었다. 가입 계정 확인 질문을 남겼으며, 이번 반영에서는 특정 회원의 역할이나 권한을 변경하지 않았다. 가입 계정 확인 후 별도 권한 행을 연결해야 한다.
