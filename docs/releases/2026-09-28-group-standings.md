# A조·B조 순위 필터 — 16차

대회 상세의 리그 순위 및 대회/순위 허브에 `전체 · A조 · B조` 선택을 추가했다. 각 조는 기존 `tournaments.groups`의 팀 ID로 구분하며 시즌 승점·득실·전적은 그대로 유지한다. 선택한 조의 순위를 1위부터 다시 표시한다.

대회 상세는 해당 대회의 조 편성을 따른다. 순위 허브는 현재 시즌에 연결된 진행 중 대회를 우선 사용하고 편성 기준 대회명을 표시한다. 시즌이 지정되지 않은 다른 대회의 조를 섞지 않는다. 운영의 정규 리그와 1필드 대회는 일부 팀의 조 편성이 다르므로 이름이나 표시 순서로 A/B를 추정하지 않는다.

기능은 `src/features/standings/`에 분리했고 기존 표 레이아웃을 재사용한다. 44px 이상 터치 영역, 선택 상태 안내, 팀 수, 키보드 포커스를 제공한다. 조 편성이 없으면 기존 전체 표를 유지한다. 새 DB 조회·컬럼·마이그레이션은 추가하지 않았다.

검수: 필터·순위·원본 불변·다른 시즌 배제 3개 테스트, TypeScript, 변경 파일 ESLint 통과. 실제 운영 컬럼 게이트를 거쳐 production build 통과.

운영 배포: `dpl_5Bjk9adx9UNxDL7ntnTTSvSuoSEK` (`https://fairground-4he26e5x1-milestones-projects-d52c4dda.vercel.app`). `fairground-kor.com`, `www.fairground-kor.com`을 이 결과물로 연결했다. 15차 선수 조회/시간 복구와 컬럼 배포 차단 기능을 포함한다.

운영 브라우저 검수: PC에서 전체 8팀 → A조 4팀 → B조 4팀 전환, 390px 모바일 에뮬레이션에서 버튼 높이 44px·필터 가로 넘침 없음·B조 순위 1~4 확인. 대회/순위 허브의 A조도 정규 리그 편성을 사용한다. `2026 1필드` 상세에서는 BOB FS가 A조이고 FC 수박은 제외되는 해당 대회의 편성을 확인했다. 실물 iPhone Safari 검수는 이번 확인 범위에 포함하지 않는다.
