# 2026-09-29 경기 시작 간격 15분

사용자 요청에 따라 기존 A구장 단일 코트의 경기 시작 간격을 20분에서 15분으로 변경한다. 경기 길이는 12분을 유지하고 팀 교대·급수·심판 리셋 시간을 8분에서 3분으로 줄인다. `src/lib/match-config.ts`의 공통 설정을 자동 편성, 큐시트 및 휴식 시간 계산에 적용한다.

- 조별 12경기: 10:00–13:00. 마지막 경기 시작 12:45, 경기 종료 12:57.
- 순위결정전 8경기: 13:00–15:00. 결승 시작 14:45, 경기 종료 14:57.
- 실내 챌린지: 10:00–14:30. 시상 15:00–15:25, 클로징·단체사진 15:25–15:30.
- 18:00 대관 종료 시각은 유지한다.

운영팀 가이드와 MC 가이드의 경기표·요약·담당자·시상·촬영 시각도 동일하게 조정한다. HTML과 모듈 버전을 갱신한다. 20경기 전체 슬롯, 조별 자동 편성·미리보기·저장 큐시트, MC 시간표의 일치 및 경기 12분 유지 여부를 회귀 테스트로 검증한다.

운영 수정은 `2026 1필드`의 기존 예정 12경기 중 시간이 달라지는 11건의 `scheduled_at`만 대상으로 한다. 첫 경기 10:00과 경기 ID, 조/번호, 홈·원정, 점수, 대회, 팀·선수·사진은 유지한다. 전체 대상 행 백업과 일치하고 모두 미진행이며 연결 기록이 없을 때만 적용한다. 다른 테이블과 대상 밖 경기도 전체 내용으로 보존 여부를 검사한다.

스키마 백업은 별도 PostgreSQL 17에 복원하고 운영 스키마 해시와 대조한다. 개발 검증은 합성 데이터만 사용한다. 스키마와 기존 마이그레이션 이력을 변경하지 않으며 기존 linked push/reset/repair 금지는 유지한다. 백업·수정 계획·검증 기록은 Git 제외 `tmp/fifteen-minute-release/`에 보관한다.

## 사전 검증

- 신규 운영 스키마 백업 561,926바이트를 격리 PostgreSQL 17에 복원했고 실제 정의 해시가 일치했다.
- 합성 12경기에서 11건의 시작 시각만 수정, 다른 필드·대회·테이블 보존, 롤백, 실행 직전 경기 상태 변경 거부를 검증했다.
- 관련 테스트 34개와 Supabase 안전 테스트 4개, lint(오류 0·기존 경고 16), TypeScript 검사를 통과했다.
