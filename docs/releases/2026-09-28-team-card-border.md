# 팀 카드 추가 테두리 제거 — 22차

BOB FS 팀카드의 파란색·금색 선은 로고나 프레임 이미지에 포함된 것이 아니었다. `isFieldChampionTeam`이 승인된 팀의 `seasonStats.rank === 1`만으로 우승을 판정하고, 공통 캔버스가 별도 윤곽선 세 겹과 반짝임을 덧그렸다. 연습 기록 초기화 후 모든 팀이 0승점인 상태에서도 정렬 순위 1위인 BOB에 적용됐다. 실제 운영 화면에서 `0W 0D 0L`과 ‘필드 우승팀’ 이미지 설명이 동시에 표시되는 것을 확인했다.

순위 기반 우승 추론과 전달 플래그, 공통 캔버스의 추가 윤곽선·광채 그리기를 제거했다. 원본 카드 프레임·로고·이름·등급 배치는 유지한다. 홈, 팀 목록, 팀 상세 및 공통 캔버스 출력 모두 동일하게 적용한다. 원본 PNG/WebP나 운영 DB를 수정하지 않는다. 갤러리 입력 타입도 공통 카드 타입을 상속하도록 통일했다.

재발 검수는 실제 렌더러로 4개 등급×2개 해상도에서 수행했다. 과거 `isFieldChampion: true`와 순위 1위 데이터가 전달돼도 일반 카드와 동일한 출력 명령이며, 추가 stroke 없이 프레임·로고·팀명을 그린다. TypeScript 통과, 린트 오류 0개·기존 경고 16개. 운영 카탈로그와 타입 컬럼 330개·조회 74개를 읽기 전용 대조한 후 빌드했다. 다른 미커밋 작업은 빌드에 포함하지 않았다.

Lazyweb의 스포츠 팀 프로필 사례는 확인했으나 이번 현상은 공통 렌더러의 자동 장식 오류여서 화면 재설계 근거로 사용하지 않았다.

배포 `dpl_Cj4bupULYhgsx2Lzsug58NyWk1yj`를 두 공식 도메인에 연결했다. 실제 운영 BOB 상세의 1080px PNG에서 추가 파란색·금색 선과 반짝임이 사라짐을 시각 확인했다. 모바일 폭 390px에서 가로 넘침 없음, 이미지 설명은 ‘BOB FS 카드’로 정상화됐다. 홈/팀 목록의 540px PNG는 바이트까지 동일했다. 검수 자료는 상위 작업 폴더 `output/ops/2026-09-28-bob-card/`에 저장했다. 실제 iPhone 기기 검증은 수행하지 않았다.
