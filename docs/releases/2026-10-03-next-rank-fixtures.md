# 다음 순위전 자동 대진과 종료 확인

13~16경기 종료 후 다음 대진을 수동으로 등록해야 했고, 이미 열린 경기 관리·홈·운영가이드의 대진도 갱신되지 않았다. 현재 컵에 한정한 DB 자동 생성과 화면 실시간 조회를 연결했다.

| 경기 | 대진 규칙 | 예정 시각 |
|---|---|---|
| 17 · 7·8위전 | 13경기 패자 vs 14경기 패자 | 15:20 |
| 18 · 5·6위전 | 13경기 승자 vs 14경기 승자 | 15:40 |
| 19 · 3·4위전 | 15경기 패자 vs 16경기 패자 | 16:00 |
| 20 · 결승 | 15경기 승자 vs 16경기 승자 | 16:20 |

정규 동점은 PK 결과로 판단한다. 모든 출전팀에는 원래 조별 순위를 표기하며, 실제 등록 행을 우선한다. 종료 순서가 바뀌거나 두 기기에서 동시에 종료해도 대진을 중복 생성하지 않는다. 운영자가 17경기 ROOT FC A팀·B팀의 양팀 기권을 지시했으므로 실제 취소 행에는 ‘양팀 기권 · 미실시’를 표시하고 승자·점수·최종 7·8위를 추정하지 않는다. 자동 생성은 이 기존 행을 보존한다.

어시스트 0회는 MOM 선정·종료를 막지 않는다. 종료 모달에 ‘어시스트 없음 확인’을 추가했고 MOM·일시정지·승부차기 저장 실패와 다른 기기 전송 대기 사유를 모달에서 표시한다. 이 검토는 가상의 어시스트 기록을 생성하지 않는다. 경기 기록 페이지의 하단 푸시 권한 배너를 숨겨 종료 버튼을 가리지 않도록 했다. 실제 기록 대기열과 동기화 가드는 유지한다.

DB: `20261003090000`만 개발·운영에 적용. 각 최신 스키마 복원본의 검증 40개가 통과했고 기존 정의 교체·일반 API 권한 추가는 없다. 개발 이력 21→22, 운영 83→84. 기존 경기·회원·집계와 준비 알림 중지 상태를 보존한다. 자동 대진은 심판의 실제 경기 종료를 대신하지 않는다.

관련 대진 해석·운영가이드 갱신·공개 API·종료 조건 테스트와 TypeScript/Lint 검사를 수행한다. 배포용 소스의 실제 개발/운영 카탈로그 대조를 통과한 정상 빌드만 배포한다. 배포 ID·최종 상태·카탈로그 및 브라우저 검증과 운영 변경의 private 증거는 저장소 밖 `output/ops/2026-10-03-next-rank-fixtures`에 보관한다.
