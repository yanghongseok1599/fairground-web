# 전체 운영가이드 협찬사별 릴스 촬영 가이드

공유 주소: https://fairground-kor.com/cup-ops#content

## 변경 내용

- 전체 운영가이드의 촬영·협찬 섹션에 즉석 이벤트 상품 배정 수량과 촬영 원칙을 추가했다. 이벤트 촬영은 `제품 시상·수상자 반응`, `제품을 들고 하는 짧은 인터뷰` 두 장면으로 한정하고, 이시맥 대표의 상세 진행표로 연결한다.
- 즉석 이벤트 배정분(아미노코치 5박스, 테이블코치 5박스, 던윅 종아리슬리브 5개, 캐터피 매직레이스 2개, 니즈 아이싱패치 10개)을 별도 칩으로 표시했다. 전체 후원 재고와 혼동되지 않도록 이시맥 대표 배정분으로 표기한다.
- 스폰서 릴스 촬영은 이벤트 촬영과 분리하고, 아미노코치·테이블코치·던윅·캐터피·니즈·썸머홀릭·준타스별 콘셉트, 촬영 시간대, 순서별 컷을 카드에 구성했다.
- 준타스는 확인된 유니폼 제작권·경기별 M.O.M 논슬립 하프삭스만 촬영 가이드에 반영했다. 팀조끼·매치볼 추가 요청은 확정 여부를 확인한 뒤 반영하도록 표시했다.
- 바른걸음연구소는 제공 품목·서비스 세부 내용이 자료에 없어 확인 대기 카드로 남겼으며, 상품 정보를 임의로 만들지 않았다. 썸머홀릭 선크림은 제품 사진 자료가 확인되지 않아 이미지 확인 표시를 둔다.
- 운영 관리 문서에 제품별 촬영 데이터와 이미지 관리 위치를 추가했다.

## 검증과 배포

- JavaScript 구문, CSS 파싱, `git diff --check` 통과.
- 모바일 390px 확인: 스폰서 가이드 카드 8개, 즉석 이벤트 컷 2개 표시; 제품 이미지 누락 0개, 이미지 프레임 넘침 0개.
- 공식 도메인의 `/cup-ops`, 버전 지정 스크립트·스타일·데이터와 준타스 이미지가 모두 HTTP 200을 반환한다.
- Vercel production 배포 `dpl_75kozAQx3DjUgMwXw2XZZoqkhGq2` (`READY`)를 공식 도메인에 연결했다.
- 이 변경에서 DB·회원 데이터·스키마·마이그레이션은 변경하지 않았다. Vercel 빌드에는 기존 Production 환경에 `SUPABASE_DB_URL`이 없어 이번 빌드 명령에만 `FAIRGROUND_SKIP_DB_PARITY=1`을 전달했다.
