# BOB 카드 흰색 로고 및 우승 카드 기준 — 24차

사용자가 우승팀 보상은 별도 효과가 아닌 플래티넘 승급이라고 정정하고, 어두운 카드에서 잘 보이지 않는 BOB 로고를 흰색으로 요청했다.

현재 premium → 플래티넘 프레임 매핑은 유지하고 [카드 정책](../team-card-policy.md)에 확정 기준을 기록했다. 순위 기반 우승 추정·추가 효과는 다시 넣지 않았다. 실제 우승팀을 지정받지 않았으므로 특정 팀의 등급을 변경하거나 자동 우승 판정 기능을 추가하지 않았다.

BOB의 등록 원본 로고로 이미지 편집을 시도했으나 빛 번짐과 윤곽 변형이 발생하여 두 결과 모두 채택하지 않았다. 사이트 카드용 캔버스에서 검정/어두운 중립색 픽셀만 흰색으로 치환한다. 알파·노랑·파랑·원본 파일은 보존하고, BOB의 고유 팀 ID에만 적용한다. 팀 상세도 해당 ID를 공통 렌더러에 전달하여 홈·팀 목록과 동일하게 표시한다.
