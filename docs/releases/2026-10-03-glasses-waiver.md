# 2026-10-03 안경 착용 전자서명 서약서

마이페이지에 안경 착용 위험과 본인 책임 범위를 확인하는 서약서를 추가했다. 회원 본인이 이름을 직접 입력하고 동의한 뒤 전자서명 제출을 누른다. 서명 완료 후 서약 원문·이름·한국 시간 서명일·버전·확인번호를 다시 조회하고 텍스트로 내려받을 수 있다. 안경 미착용 회원에게 서명을 강제하거나 경기 장비 규정을 변경하지 않는다.

본인의 안경 착용 선택·부주의에 귀속되는 책임을 확인하되, 주최·운영 측 또는 다른 참가자의 고의·과실 등 법률상 책임을 일괄 배제하지 않는다. 관련 참고: [약관법 제7조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025032399). 본인 계정과 이름 확인에 기반한 전자서명이며 외부 인증기관의 인증서는 사용하지 않는다.

`src/features/glasses-waiver/`에 문구·API·UI를 분리했다. DB에는 서명 당시 원문과 이름, 회원 ID, 서버 시각, 버전을 저장하며 같은 회원·버전의 재제출은 최초 기록을 반환한다. 익명 실행, 다른 회원 기록 조회, API 직접 INSERT/UPDATE/DELETE를 차단했다. 서명한 회원의 프로필 삭제는 FK로 보호되므로 관리자가 계정 삭제를 수행할 때는 서명 기록 보존·삭제 정책을 함께 검토해야 한다.

SQL `20261003070000_glasses_waiver.sql`만 개발·운영 각각 최신 스키마 백업·격리 복원·전체 정의/권한 대조·diff·롤백·합성 API 역할 검증 후 적용했다. 기존 객체 정의 변경은 0건이고 서약 전용 정의 40건을 추가했다. 개발 백업 558,168바이트·5,815개 정의, 운영 백업 607,492바이트·5,139개 정의를 검증했다. 개발 기존 33개 테이블(합성 회원 15명·경기 3개), 운영 기존 32개 테이블(회원 135명·경기 12개)의 모든 기존 행 해시를 보존했다. 마이그레이션 이력은 개발 19→20건, 운영 81→82건이며 기존 이력은 동일하다. linked push/reset/repair는 실행하지 않았다.

두 격리 복원 DB에서 서약 테스트 6개씩 모두 통과했다. 비로그인 접근, 동의 누락, 이름 불일치, 서버 시각·원문 일치, 동시/재제출, 직접 조회·변조·삭제 차단, 이름 변경 후 기존 영수증 보존을 확인했다. Supabase 안전 테스트 4개, TypeScript, lint(기존 경고 16개·오류 0개)를 통과했다.

백업·diff·적용 영수증은 작업폴더 `output/ops/2026-10-03-glasses-waiver/`에 제한 권한으로 보관한다. 웹 빌드·배포 결과는 이 기록의 최종 상태에 추가한다.
