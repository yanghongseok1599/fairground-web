# 기업 후원 제안서 미디어 복구

일반 기업용, 준타스, 펄스나인 제안서의 원본 이미지 40개가 운영에서 404를 반환했다. 페이지 자체는 200이었지만 Next Image 요청도 원본 누락으로 400을 반환했다. 해당 파일은 로컬 `public/proposals`에 존재하나 Git에 등록되지 않아 앞선 격리 배포에서 제외됐다.

기존 제안서 데이터가 참조하는 이미지 46개와 동영상 3개만 등록했다. 이전 시안과 별도 ROOT FC 유니폼 제안서 파일은 포함하지 않았다. 원본 이미지, 제안 문구, 레이아웃은 수정하지 않았다.

`scripts/proposals/check-media-assets.mjs`는 TypeScript AST로 현재 데이터의 경로를 수집한다. 공통 로고를 포함한 52개 파일의 존재를 검사하고, Git 저장소에서는 추적 여부도 확인한다. `prebuild`는 기존 DB 정합성 검사와 이 검사를 모두 통과해야 빌드를 진행한다.

누락 파일, 미추적 파일, Git 정보 없는 배포 아카이브의 검수 3건을 통과했다. 격리 소스의 Lint는 오류 0개(기존 경고 16개), TypeScript와 개발 DB 카탈로그 대조 및 정상 빌드를 통과했다. DB·회원·경기 기록·설문 응답·권한·원격 환경변수는 변경하지 않는다.

운영 배포 ID와 상태, 실제 이미지 HTTP/브라우저 검수 및 산출물 정리 결과는 저장소 밖 `../output/ops/2026-10-09-proposal-media/web-release.json`에 기록한다.
