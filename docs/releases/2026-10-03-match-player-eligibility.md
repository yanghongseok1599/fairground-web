# 경기 명단의 선수 출신 참가 제한 반영

경기 기록 화면이 공개 프로필을 그대로 읽어 선수 출신을 포함했다. 공개 프로필에는 `has_player_experience`가 없어 클라이언트 필터만으로는 제외할 수 없었다. ROOT FC B팀 김한주 감독 계정도 선수 출신 값이 false였으며, 별도의 무소속 동명 계정은 이미 true였다.

사용자 확인에 따라 **감독·주장·매니저라는 팀 직책으로 출전을 제한하지 않는다.** 선수 겸 감독·주장은 기존 참가 자격을 충족하면 경기 명단에 남는다.

## 변경

- `public_match_player_profiles` 읽기 전용 뷰를 추가했다. 기존 공개 프로필의 승인·징계 조건과 공개 컬럼 범위를 유지하고, 선수 출신만 서버에서 제외한다. 전화번호·생년월일·팀 직책 등 비공개 컬럼은 추가하지 않는다.
- 경기 기록·중계 및 라인업 선수 선택은 참가 자격을 반영한 명단을 조회한다. 기존 사진 제외 경량 조회와 오류 처리를 유지한다. 일반 공개 프로필과 팀 관리 명단은 보존한다.
- 기존 `ccv5` 관리자 브라우저에서 ROOT FC B팀 김한주 계정을 `선출로 지정`했다. 대상 행 백업과 변경 후 대조 결과 `has_player_experience` 하나만 false→true로 바뀌었다. 팀 소속·감독 역할·승인·사진·개인정보는 동일하며 무소속 동명 계정은 변경하지 않았다. 대상의 기존 라인업 등록은 0건이다.

## DB 검증과 운영 적용

- 최신 운영 스키마 580,702바이트를 격리 로컬 PostgreSQL에 복원했다. 기존 정의/권한/제약조건/뷰 4,807개와 일치했고 기존 마이그레이션 이력 73건을 확인했다.
- 동일 SQL의 적용·롤백을 검증했다. 기존 정의 제거/변경 없이 신규 뷰 관련 225개 정의만 추가됐다.
- 실제 anon/authenticated 역할에서 선수 겸 감독·주장 유지, 선수 출신·미승인·징계 회원 제외, 비공개 컬럼 미노출, 쓰기 권한 없음, 관리자 참가 자격 정정 및 기존 서버 출전 제한 테스트 3건을 통과했다. 합성 데이터만 사용했고 모두 롤백했다.
- `20261003020000` 한 건을 운영에 적용했다. 33개 보호 테이블과 회원 132명의 기존 데이터, 기존 이력 73건을 보존한 후 새 이력 1건만 추가했다. 이후 위 관리자 UI 작업에서 지정된 1명의 참가 자격만 정정했다.
- hosted 개발 DB에는 아직 반영하지 않았다. 전체 마이그레이션 이력 불일치와 linked push/reset/repair 금지는 유지한다.
- 운영 조회에서 ROOT FC B팀의 공개 명단 9명은 유지되고 경기 명단 8명에는 김한주 감독이 없다.
