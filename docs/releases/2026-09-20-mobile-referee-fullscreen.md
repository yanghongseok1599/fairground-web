# 모바일 심판 전체화면 기록 — 2026-09-20

심판이 모바일에서 점수·시간을 보면서 전체 선수의 기록을 입력할 수 있도록 **전체화면 기록**을 추가했다. 경기 시작 전부터 열 수 있고, 상단의 전광판과 시작·일시정지·재개·종료 버튼은 고정된 상태로 선수 명단만 스크롤된다. 세로 화면은 팀 선택, 넓은 가로 화면은 양 팀 병렬 명단을 사용한다.

**기록 내역**에서 취소·어시스트 보강도 가능하다. 종료 확인과 MOM 선택을 기존 화면과 공용으로 묶어 전체화면에서도 동일한 확인 절차를 거친다. 팝업 Escape는 팝업만 닫고, 화면 우측 상단의 닫기 버튼은 경기를 유지하며 일반 화면으로 돌아간다. 종료 후에는 최종 스코어를 유지하고 기록 입력을 잠근다.

`referee-recording-fullscreen.tsx`가 고정 전광판과 스크롤 영역을 담당하고 `use-recording-fullscreen.ts`가 브라우저 전체화면·스크롤 잠금·해제를 담당한다. native API가 없거나 거부되는 iPhone 환경에도 뷰포트 크기와 safe-area를 사용하는 대체 화면이 열린다. 강제 회전 없이 현재 세로·가로 방향을 따르며 참가자 경기장 중계는 그대로 유지한다.
