# 이시맥 대표 MC 진행표

공유 주소: https://fairground-kor.com/cup-ops/simaek

이시맥 대표가 시간대별 공식 챌린지와 경기 사이 운영 제안을 확인하고, 상품 이미지와 수량까지 한 페이지에서 볼 수 있도록 만들었다. 기존 [운영팀 가이드](https://fairground-kor.com/cup-ops) 첫 화면에도 전용 진행표 링크를 추가했다.

## 진행 내용

- 공식 일정: 09:00 팀 소개, 09:20 단체 몸풀기, 12:30 원팀챌린지, 14:30 등바구니 공받기, 15:00 슈팅왕 속도대결, 15:40 시상·승급 발표, 16:05 클로징.
- 선수대기실 미니 이벤트는 `5초 팀응원 구호 릴레이`로 제안하고, 경기 중이거나 다음 경기 호출을 받은 선수는 부르지 않도록 안내했다. 실제 대기실 사용시간은 시설 확인이 필요하다고 표시했다.
- 브리핑에 적힌 이시맥 대표 이벤트 상품 수량 5종에 상품 사진을 붙였다. 종목별 상품 연결·수상 인원은 운영 제안으로 구분했고, 던윅 사이즈 확인 메모를 넣었다.
- 경기 규칙과 우승 판정은 제공 자료에 세부 기준이 없어 임의로 정하지 않고 당일 운영 큐시트 확인 항목으로 남겼다.
