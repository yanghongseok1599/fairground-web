# 경기 결과 카카오·OG 공유

종료 경기의 공유 주소를 `/share/matches/<id>?v=<홈점수>-<원정점수>`로 변경했다. 카카오 feed의 imageUrl은 같은 경기의 `/image` PNG를 사용하며 링크를 복사해 전달할 때도 전용 페이지의 OG/Twitter metadata가 결과 이미지를 가리킨다. 대회 공유는 기존 공통 이미지를 유지한다.

1200×630 이미지에 대회명·라운드·두 팀명·최종 점수를 표시한다. 서버 데이터 조회·이미지 디자인·링크 생성·라우트를 역할별 모듈로 나눴다. Paperlogy Bold 글꼴과 OFL 원문을 함께 보관하고 외부 폰트 조회에 의존하지 않는다. PNG는 React 텍스트와 고정 스타일로 렌더링하며 사용자 문자열을 SVG에 삽입하지 않는다.

이미지와 전용 페이지는 publishable key의 익명 RLS 조회만 사용하며 서버에 저장된 종료 경기만 표시한다. 입력 URL의 점수나 팀명을 신뢰하지 않고 DB에서 다시 읽는다. 예정/진행 경기·잘못된 ID는 404이며 DB 장애를 잘못된 0:0 결과로 치환하지 않는다. 점수 정정 후 재공유는 새 이미지 URL을 사용한다. 이미 전달한 메시지의 카카오 캐시는 강제로 수정할 수 없다.

Lazyweb 화면 검색은 HTTP 429 요청 제한으로 실패하여 기존 FairGround 네이비·화이트 디자인을 사용했다. 참고: https://developers.kakao.com/docs/ko/kakaotalk-share/js-link

검증: 카카오 공유와 대체 동작, 결과 링크/점수 수정 URL/익명 종료 경기 필터/장애 처리 테스트 통과. 실제 Next ImageResponse에서 합성 3:2 PNG를 렌더링해 한글·팀명·점수를 시각 확인했다. 관련 없는 미완료 작업을 제외한 격리 소스에서 전체 소스 lint 오류 0, TypeScript와 개발 카탈로그 검사를 유지한 npm run build 통과.

운영 익명 조회 시 종료 경기 0건이므로 실제 결과 링크의 성공 검수와 카카오 메시지 미리보기 검수는 첫 경기 종료 후 가능하다. 검수 목적으로 실제 경기를 종료하거나 점수를 변경하지 않았다. DB·권한·회원·경기 기록은 변경하지 않는다.
