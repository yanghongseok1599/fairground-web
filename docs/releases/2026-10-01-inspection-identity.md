# 검인 명단 팀·생년월일 표시

선수검인 명단에서 이름·등번호 옆에 소속팀과 생년월일을 함께 표시한다. 좁은 화면에서는 같은 정보 영역 안에서 줄바꿈하며, 생년월일이 없는 선수는 `미등록`으로 표시한다. 기존 검인 RPC가 반환하는 `birth_date`를 사용하며 DB·API·권한 및 회원/검인 데이터는 변경하지 않았다.

UI 참고: [Lazyweb 회원 명단 패턴](https://www.lazyweb.com/agentic-search/83c2881c-5693-428d-9491-5f17c0665e0a). 신원 확인에 필요한 정보를 이름 가까이에 묶는 방식을 적용했다.

## 검증

- 기존 선수검인 테스트 8건 통과, Supabase 환경 안전 검사 통과.
- 배포 소스 린트 오류 0개(기존 경고 16개), TypeScript 검사 통과.
- 실제 운영 DB 카탈로그와 코드 조회 컬럼/RPC 대조를 포함한 production 빌드 통과. 검사 우회 없음.
- 배포 산출물의 임시 DB 비밀번호 포함 여부 검사 통과.
- 공식 도메인의 기존 관리자 세션에서 78명 모두 소속팀·생년월일 항목을 확인했다. 등록된 생년월일 26건, 미등록 표시 52건이며 화면 가로 넘침이 없다.
- 실제 운영 명단의 표시만 확인했고 검인 완료·취소 처리는 실행하지 않았다.
