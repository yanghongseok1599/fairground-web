# 현장 생년월일 입력·검인 동기화

검인 명단의 일반 관리자 계정에 생년월일 `입력`/`수정`을 추가했다. 숫자 8자리 또는 `YYYY-MM-DD`를 직접 타이핑하고 저장한다. 날짜 유효성 검사, 실패 시 입력 보존, 자동 갱신 중 초안 보존, 저장 직전 기존 값/팀 확인 및 변경 행 확인을 포함한다. 기존 `profiles` RLS를 사용하며 검인 전담 계정에 일반 회원 편집 권한을 추가하지 않았다. 사전 조회와 UPDATE는 별도 요청이므로 원자적 동시 수정 방지는 아니다.

가입·선수정보 수정·팀 가입 승인·참가 자격/조 편성 변경·검인/생년월일 저장 후 개인정보 없는 Broadcast 갱신 신호를 보낸다. 관리자 명단과 참가자 검인 카드는 자신의 RPC로 다시 조회하며 5초 재조회, 화면 복귀 및 연결 복구 재조회도 유지한다. 신규 가입자는 참가팀 소속이 확정되어야 명단에 포함된다. 선수 가입 미승인은 표시하되 검인 완료 제한을 유지한다.

[UI 참고](https://www.lazyweb.com/agentic-search/3d163f8e-9bc4-4e39-8bd5-d68778854c96), [Supabase Broadcast 문서](https://supabase.com/docs/guides/realtime/broadcast).
