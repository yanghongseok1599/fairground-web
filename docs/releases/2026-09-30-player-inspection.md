# 2026-09-30 현장 선수검인 구현·로컬 검증

상태: **구현 및 격리 DB 검증 완료. Hosted 개발 DB·운영 DB 적용과 웹 배포는 하지 않았다.**

관리자 운영 콘솔 첫 항목에 현장 선수검인을 추가했다. 전체/완료/미검인 집계, 팀별 필터, 이름·팀·등번호 검색, 본인확인 창, 완료·취소를 지원한다. 참가자 마이페이지 상단은 대회별 완료 여부·완료 시각을 표시하고 15초 주기로 갱신한다. 통신 실패를 미검인이나 완료 성공으로 처리하지 않는다.

신규 SQL `20260930010000_player_inspections.sql`은 전용 테이블 1개, 내부 범위 판정 함수 1개, 읽기/쓰기 RPC 3개를 추가한다. 기존 프로필·회원 승인·사진·경기 데이터는 수정하지 않는다. 참가자 본인 조회, 관리자 전용 검인, 서버 시각·처리자 기록, 오래된 revision 차단을 포함한다.

## 검증 근거

- 2026-09-29 등번호 작업의 스키마 전용 덤프를 시스템 임시 폴더의 별도 PostgreSQL 17 인스턴스(55439)에 권한·RLS·Auth 트리거 포함 복원했다. 실제 회원 데이터는 복사하지 않았다.
- 그 덤프 이후의 `20260929020000`과 이번 SQL을 적용했다. 현재 작업공간에 이미 있는 별도 퀴즈 기능의 미커밋 SQL 및 빈 `team-galleries` 버킷도 **로컬 검증 DB에만** 추가하여 전체 소스의 정합성 게이트를 실행했다. 이 퀴즈 변경은 이번 커밋에 포함하지 않는다.
- 실제 `anon`/`authenticated` 역할을 사용하는 합성 DB 검수 8개 통과: 명단 범위, 관리자 권한, 직접 조작 차단, 자격 제한, 대회별 분리, 완료/취소, revision 충돌, 팀·승인 변경 반영. 모든 테스트 데이터는 롤백했다.
- 정책/API/요청 시간 제한 테스트 8개, 기존 관리자 선수 조회 8개, 관리자 메뉴 검사 통과. Supabase 안전장치 4개, 스키마 게이트 21개, 기존 보안 회귀 7개 통과.
- TypeScript 및 lint 통과(기존 경고 16개, 오류 0개). **격리 DB를 실제 조회하는 prebuild 게이트를 포함한 `npm run build` 통과**. 운영 배포용 환경변수나 우회 플래그를 사용하지 않았다. 이 산출물은 운영 배포용이 아니다.
- Ego 브라우저에서 합성 API 응답을 사용해 검색, 본인확인 전 완료 버튼 비활성, 완료 후 목록/참가자 카드 반영, 통신 실패 안내를 점검했다. 390px 화면에서 관리자 목록과 참가자 검인 카드의 가로 넘침 없음. 실제 휴대폰 하드웨어 검수는 하지 않았다. 브라우저 스크린샷 기능은 타임아웃되어 DOM/상호작용 검수로 확인했다.
- `npm audit --audit-level=moderate`는 기존 의존성 6건(low 1 / moderate 3 / high 2)으로 실패했다. 패키지 및 잠금 파일은 이번 작업에서 변경하지 않았다.

## 원격 반영 전 남은 사항

개발·운영 환경 분리는 정상이다. Hosted 개발 DB의 읽기 전용 조회에서 기존 `number_label` 컬럼이 아직 없음을 확인했다. 운영 CLI의 이력 읽기는 연결 시간 초과로 실패했고, 기본 빌드는 운영 `SUPABASE_DB_URL` 미설정으로 게이트에서 차단됐다. 따라서 이번 검증은 현재 원격 스키마의 동일성을 증명하지 않는다.

원격 반영 때는 최신 스키마 백업·실제 diff·기존 미반영 변경의 정합성 확인·개발 재현을 먼저 마친 뒤 같은 SQL만 적용하고 해당 대상 DB로 배포 게이트를 다시 실행해야 한다. 기존 `db push`/linked reset/migration repair 금지는 그대로 유지한다.
