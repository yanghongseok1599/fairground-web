## 최초 구현 검증 당시 원격 상태

개발·운영 환경 분리는 정상이다. Hosted 개발 DB의 읽기 전용 조회에서 기존 `number_label` 컬럼이 아직 없음을 확인했다. 운영 CLI의 이력 읽기는 연결 시간 초과로 실패했고, 기본 빌드는 운영 `SUPABASE_DB_URL` 미설정으로 게이트에서 차단됐다. 따라서 이번 검증은 현재 원격 스키마의 동일성을 증명하지 않는다.

원격 반영 때는 최신 스키마 백업·실제 diff·기존 미반영 변경의 정합성 확인·개발 재현을 먼저 마친 뒤 같은 SQL만 적용하고 해당 대상 DB로 배포 게이트를 다시 실행해야 한다. 기존 `db push`/linked reset/migration repair 금지는 그대로 유지한다.

### DB 적용 근거

1. 개발 DB의 `public`, `auth`, `storage`, `supabase_migrations` 스키마를 새로 백업하고 시스템 임시 폴더의 별도 PostgreSQL 17(55440)에 역할·확장 포함 복원했다. search_path를 통일한 정의/권한 서명 5,338개가 정확히 일치했다.
2. 개발에 미반영된 등번호 SQL `20260928030000`, `20260929020000`과 검인 SQL `20260930010000` 3개만 재현했다. 실제 전후 정의 diff를 확인했고 롤백 시 기존 서명이 복원됐다. 검인·등번호 실제 DB 역할 테스트 15개가 통과했다.
3. 동일 SQL을 개발 DB의 단일 트랜잭션에서 적용했다. 적용 직전 정의/이력이 백업과 일치하고 적용 후 정의가 격리 재현과 일치함을 확인했다. 기존 32개 보호 테이블의 행 해시와 기존 이력 4건은 보존했고 새 버전 3개만 추가했다. 이후 별도 합성 시연 대회 1건을 추가했다.
4. 실제 관리자·선수 인증 세션으로 명단 9명 조회 → 김하늘 검인 완료 → 본인 마이페이지 RPC 완료 → 관리자 취소 → 본인 미검인 반영을 확인했다.
5. 배포된 Preview에서 관리자 로그인 → 김하늘 본인확인 체크 → 검인 완료 처리 → 선수 로그인 → 마이페이지 `검인완료` 표시를 실제 브라우저로 확인했다. 시연 시작을 위해 해당 검인은 다시 미검인으로 되돌렸다.
6. Vercel Preview 공개 환경변수가 개발을 가리키는지 확인하고 개발 DB 연결을 빌드 프로세스에 주입했다. 우회 없이 실제 카탈로그 게이트(함수 39개·관계 27개·타입 컬럼 333개·조회 컬럼 78개) 및 전체 `npm run build`가 통과했다. Preview 사전 빌드 산출물을 배포했다. Production 승격은 하지 않았다.

민감한 연결 정보가 없는 적용 영수증·스키마 덤프·diff는 작업공간 상위 `output/ops/2026-09-30-player-inspection-development/`에 보관한다. 현재 전체 마이그레이션 기준선 불일치는 해소되지 않았고 linked push/reset/repair 금지는 유지한다. 운영 CLI 로그인 발급 및 기존 운영 읽기 전용 연결이 시간 초과하여 이번 검인 SQL을 운영에 적용하지 않았다. 운영 반영은 신규 백업·복원·실제 diff·카탈로그 빌드를 다시 통과한 뒤 별도로 수행해야 한다.


## 시연 링크의 Vercel 로그인 차단 수정

첫 전달 주소는 Vercel Authentication으로 보호되어 있었다. 당시 브라우저 검수가 기존 Vercel 인증 세션을 사용했으므로 외부 방문자 접근을 확인한 것이 아니었다. 실제 비인증 요청은 `vercel.com`으로 302 리다이렉트됐다.

해당 시연 배포 `dpl_3fZgxgZs6UgNKt7odADEd9RGYJoN`에만 7일 만료 공유 링크를 생성했다. 프로젝트 전체 보호 설정과 운영 배포는 변경하지 않았다. 기존 쿠키 없는 HTTP 요청에서 공유 링크가 접근 쿠키를 발급하고, 같은 배포의 FairGround 화면·앱 자산을 200으로 반환하는 것을 확인했다. 공유 토큰은 저장소에 기록하지 않고 사용자에게 직접 전달했다.

Hosted 개발 Auth 설정의 Google·Kakao 공급자는 비활성이고 이메일 로그인이 활성이다. 시연은 기존 개발 이메일 계정을 사용한다. 운영 로그인 서비스 조회와 CLI DB 연결은 시간 초과하여 실시간 운영 인증 확인은 완료하지 못했다. 운영 계정·암호·권한은 변경하지 않았다.
