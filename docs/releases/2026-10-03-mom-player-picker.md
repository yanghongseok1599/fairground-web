# 경기 종료 MOM 검색·스크롤 안정화

경기 종료 화면의 긴 MOM 드롭다운이 공동 기록의 주기적 갱신 때 다시 배치되면서 목록을 위로 되돌렸다. 종료 MOM 선택을 다이얼로그 내부의 높이가 제한된 라디오 목록으로 교체했다. 등번호·선수명·팀명 검색과 팀 필터로 같은 등번호의 선수를 구분한다. 일반 화면과 가로 전체 화면은 동일한 선택 컴포넌트를 사용한다.

선택 컴포넌트와 검색 함수를 별도 모듈로 분리했다. 경기 종료 조건, 명시적인 MOM 없음 선택 조건, 승부차기·MOM·종료 저장 순서는 유지한다. DB 스키마와 실제 기록 대기열은 변경하지 않는다.

검증: 검색·종료 조건 테스트 7개, Supabase 안전 테스트 4개, TypeScript 검사 통과. 전체 Lint는 오류 0개와 기존 경고 16개다. 배포 소스를 hosted 개발 카탈로그와 대조해 타입 컬럼 368개·조회 100개를 확인했다. 임시 합성 선수 화면에서는 400ms마다 새 객체로 갱신하며 20회 동안 스크롤 위치가 유지되고, BOB FS 99번 검색·선택이 후속 갱신에도 유지됨을 확인했다.

현장 요청에 따라 15경기의 MOM을 승인된 BOB FS 99번 구준형으로 저장하고 커밋 후 재조회했다. 당시 정규 점수 0:2, 진행 상태, 시계·이벤트·명단·통계를 보존했다. 경기 종료·중지는 실행하지 않았다. 개인정보를 포함하는 운영 증거는 저장소 외부의 `output/ops/2026-10-03-mom-scroll-fix`에 보관한다. 배포 ID·최종 상태와 브라우저 검수 결과도 같은 폴더에 기록한다.
