# 2026-10-14 개발 lint 정리와 전체 재검증

## 변경 범위

기존 lint 경고 16개를 정리했다. 운영 DB 연결·조회·변경, 웹 배포와 Git 푸시는 수행하지 않았다. 기존 작업 중인 소스와 미추적 파일은 보존했다.

- 소개·마이페이지·팀 로고 미리보기·엠블럼·코트·선수카드 이미지 12곳을 `next/image`로 전환했다. 기존 CSS·원본 URL을 유지하며 `unoptimized`, `loading="eager"`, `decoding="auto"`로 화면 밖 PNG 캡처와 업로드 data URL의 동작을 보존했다.
- 선수카드 국기·처리된 팀 로고 2곳은 가변 원본 비율과 작은 원본의 비확대 동작이 필요해 native `img`를 유지했다. 해당 두 줄에만 이유를 설명하는 `no-img-element` 예외를 두었으며 전역 규칙은 변경하지 않았다.
- 관리자 팝업의 `loadDraft`·`reload`를 안정된 `useCallback`으로 만들고 초기 Effect가 `reload`를 의존하도록 했다. 기존 초기 조회·선택·저장·삭제 경로는 유지했다.
- 팀 게시판의 로그인 이동을 `router.push`로 바꾸고 기존 `returnTo`를 유지했다.

## 검증 결과

프로젝트 밖의 임시 작업본에 전체 현재 소스와 lockfile을 복사하고 `npm ci`로 설치했다. 운영 환경 파일은 복사하지 않았다.

| 검사 | 결과 |
|---|---|
| `npm run lint -- --max-warnings=0` | 오류 0, 경고 0 |
| 비DB 테스트 | 121개 파일, 674개 통과 |
| DB 테스트 | 27개 파일, 178개 통과 |
| 전체 테스트 | 148개 파일, 852개 통과; 실패·취소·스킵·todo 0 |
| `npx tsc --noEmit` | 통과 |
| `npm audit --json` | 모든 심각도 합계 0건 |
| `npm run build` | 개발 카탈로그 게이트 포함 통과, 59페이지 생성 |
| 로컬 HTTP 검사 | 14개 경로와 CSS·사이트맵·robots 정상 |

정상 prebuild 경로에서 개발 DB와 타입 컬럼 370개·조회 103개를 대조했으며 함수 118개·릴레이션 39개·버킷 1개를 확인했다. 우회 플래그나 직접 `next build`는 사용하지 않았다. `npm run supabase:safety`로 로컬 설정의 개발/운영 분리를 확인했다. CLI는 운영에 연결되어 있으므로 linked 명령은 실행하지 않았다.

## DB 검증 격리

확인된 개발 연결만 읽기 전용으로 사용해 최신 스키마를 새로 백업했다. 백업은 611,705바이트이며 SHA-256은 `6bf72053610291960cc59f8931615c55690e0c75db04efd41d71ea58de3938f6`이다.

PostgreSQL 17 로컬 복원본의 1,742개 정의·소유자·권한·RLS가 개발 카탈로그와 완전히 일치했다. `pg_dump`가 생략하는 소유자 기본 권한 표현 1곳을 같은 권한으로 복원한 뒤 diff 0을 확인했다. 앱 테이블 71개가 빈 상태인 템플릿을 각 테스트 파일마다 복제하고 합성 데이터로 검사했다. 개발 이력 29건, 함수 스냅샷의 RLS/접근 차단, 준비 알림 중지를 확인했으며 hosted 데이터·스키마·예약 작업은 변경하지 않았다. 검사 뒤 기본 복원 스키마가 동일했고 임시 PG17 서버와 클러스터를 정리했다.

## 이미지 회귀검증

- 설치된 Next 16.3.8 이미지 문서와 실제 이미지 props 처리를 검토했다.
- 변경 전후 실제 React SSR을 27개 시나리오·134개 이미지에서 비교해 URL·접근성 속성·기존 CSS·스타일 보존을 확인했다.
- 브라우저에서 코트·엠블럼·선수카드의 이미지 위치·크기·원본 치수가 같고 모두 로드됨을 확인했다.
- 실제 `elementToPngBlob` 구현으로 합성 선수카드를 변경 전후 각각 내보냈다. 두 PNG 모두 2160×2700, 4,592,404바이트이며 파일 바이트가 동일했다. SHA-256: `bc3d9a8fe46148549d3f1b3e1417d0454f662973f09c2b0f0cb1100f19d7ad6b`.
- 소개 페이지도 로컬 빌드 브라우저에서 확인했다. 모든 사용자 사진·기기별 내보내기 조합을 검증한 것은 아니다.

검증 로그·백업·해시·diff는 Git 밖 Codex Security 아티팩트의 `artifacts/2026-10-14-lint/`에 보관한다. 임시 QA 페이지는 원본 저장소에 추가하지 않았다.

## 보안·테스트·lint 개발 Preview 릴리스 범위

최종 배포 범위는 이번 대화에서 수정한 의존성 취약점, 개발 DB 권한·퀴즈 RPC SQL, 테스트 복구, lint 정리다. 기준 커밋 `d10920d`에서 관련 파일만 별도 worktree로 분리했다. 새 퀴즈 UI·엔진·이미지·메뉴와 제안서, 과거 Preview 복구 문서는 다른 작업이므로 제외했다. 퀴즈 SQL과 DB 역할·입력·재전송 회귀검사는 포함한다.

개발 Preview 공개 API 주소가 개발을 가리키고 운영 브랜치가 `main`임을 확인했다. GitHub Actions의 DB 시크릿은 환경이 명시되지 않아 커밋의 `[skip actions]`로 해당 push 자동 실행을 제외한다. 최종 추적 소스의 개발 DB 검증과 Vercel Preview의 정상 prebuild 게이트는 유지한다. Production 브랜치·도메인·환경변수는 변경하지 않는다.

앞 절의 852개·59페이지 결과는 새 퀴즈 UI와 제안서를 포함한 전체 작업본의 검증 기록이다. 이번 릴리스에는 해당 UI 테스트 5개와 페이지 2개를 제외했다. 최종 커밋 후보의 147개 파일·847개 테스트(비DB 669개, DB 178개), lint 오류·경고 0, TypeScript, 의존성 감사 0건, 정상 개발 빌드 57페이지를 다시 확인했다. 현재 개발 카탈로그와 앞선 백업의 정의·역할·이력이 일치한 뒤 로컬에서 전체 DB 테스트를 재실행했으며 실제 개발 DB 쓰기는 없었다. 배포 SHA·최종 상태·브라우저 검수 결과는 별도 릴리스 증거에 보관한다.
