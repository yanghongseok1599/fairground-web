# 홈 대회 결과 글래스 탐색 버튼

홈 영상 위에 반투명 글래스 선택 버튼 6개를 배치했다. 대회 결과·득점왕·골레이로왕·남자 MOM·여자 MOM·경기별 MOM을 선택하면 바로 아래 결과 패널을 전환한다. 모바일에서는 버튼 영역만 가로로 스크롤하며, 클릭 시 패널로 이동하고 키보드 선택은 페이지 위치를 유지한다.

결과를 불러오거나 탭을 전환해도 같은 영상 DOM과 재생 시간을 유지한다. 기존 데스크톱 21:9·모바일 16:9, 무음 자동재생·반복·정지 기능과 미디어 파일은 유지한다. `home-result-tabs`, `home-results-navigation`, `home-results-panel`, `home-results-explorer`로 역할을 분리하고, 대회 상세에서도 사용하는 수상 카드와 경기별 MOM 렌더러를 공용 모듈로 추출했다. 결과 집계 모델·API·DB·실제 수상 데이터는 변경하지 않는다.

디자인은 [Rimini Wellness 실제 홈페이지](https://www.riminiwellness.com/en)와 [Lazyweb 화면 근거](https://www.lazyweb.com/agentic-search/fcb156a7-5a74-441a-8b93-0b6da0939e33)를 참고했다.

## 검증

기준 소스 `cd1e999`의 격리 worktree에서 코드 10개와 이 기록만 출시한다. 기존 dirty/untracked 파일 173개를 해시·상태로 보존하며 임시 QA 페이지는 제거했다.

- `npm ci --include=dev`: 잠금 파일 유지. 기존 의존성 감사 결과는 이번 변경에서 수정하지 않았다.
- `npm run lint`: 오류 0개, 기존 경고 16개. 공식 Next 타입 생성 후 일반 `npx tsc --noEmit` 통과.
- 기존 컵 결과·최종순위 테스트 14/14 통과. 공용 렌더러 추출 전후 기본 HTML 6개 사례 동일.
- 실제 개발·운영 DB 카탈로그 검사 모두 실행되어 누락 0개. `vercel build --prod`의 정상 prebuild에서 함수 44개·릴레이션 28개·버킷 1개, 컬럼 계약 370개·조회 103개를 대조하고 Next 빌드·54개 정적 페이지·배포 출력 생성까지 통과.
- 데스크톱·모바일·768px 태블릿 브라우저 검수 통과. 6개 패널, 득점 동률 전원·미확정 골레이로 이름·남자 잠정/여자 확정 표시·경기별 MOM 상태를 확인했다. 로딩 전후 같은 영상에서 재생 시간 0.8→13초를 확인했다.
- 방향키·Home·End 순환 선택, ARIA·포커스·페이지 위치 유지, 모바일 가로 이동·본문 넘침 없음, 동작 감소 설정의 즉시 이동·영상 정지를 확인했다. 최종 포커스 여백 8px와 가로 스크롤 여백 20px는 운영 화면에서 재확인한다.

자동 Preview의 실제 DB 게이트와 Ready를 확인한 뒤 검증된 Production 빌드를 배포한다. 기존 GitHub Actions의 `SUPABASE_DB_URL` secret 누락은 별도 설정 문제이며 환경변수·DB·권한·의존성을 변경하거나 빌드 게이트를 우회하지 않는다.
