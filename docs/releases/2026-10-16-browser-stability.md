# 2026-10-16 개발 Preview 브라우저 자동화 안정화

## 범위와 검증 상태

`feat/site-essentials`의 개발 Preview에서 팀 카드 클릭과 팀 정보 수정 취소를 무인으로 끝까지 검증하기 위한 테스트 실행기 변경이다. 기존 `40ee2e3` 검증에서 확인된 확장 프로그램 간섭과 취소 후 고정 헤더에 가려지는 버튼 처리를 대상으로 한다. 제품 UI·업무 로직·DB 스키마·권한은 변경 대상이 아니다. 운영 DB·웹·배포·환경변수도 변경하지 않는다.

배포 전 검증에서 비DB 테스트 791개(브라우저 실행기 단위 테스트 104개 포함), lint 경고 0개, 타입 검사, 의존성 감사 0건과 정상 개발 빌드가 통과했다. 빌드는 읽기 전용 개발 DB 연결로 기존 prebuild 정합성 게이트를 실행했다. DB/제품 코드 변경이 없어 이번 작업에서는 DB 쓰기 테스트를 다시 실행하지 않았다.

기준 Preview `40ee2e3`에서 수정된 실행기로 8개 기능 사례가 수동 개입 없이 끝까지 통과했고, 실제 헤더 복구 2회·취소 구간 앱 쓰기 0건·로그아웃·확장 원상복원을 확인했다. 이후 정확한 커밋의 자동 Preview READY 상태와 최종 무인 재실행 결과는 Git 밖 Codex Security 증거 묶음 `artifacts/2026-10-16-browser-stability/`의 `report.md`, `deployment.json`, 각 실행의 `results.json`·`session.json`·`extension-receipt.json`으로 기록한다.

## 변경 내용

- 확장 격리는 `--isolate-extension aliprice`로 명시한 경우에만 실행한다. 알려진 ID `fahhlhbhnmkjegdfoiadmnhcclidoflh` 한 개의 원래 활성 상태를 기록하고, 테스트 동안 일시 중지한 뒤 `finally`에서 원래 상태로 복원한다. 같은 브라우저의 다른 탭에도 일시 영향을 주므로 실행 옵션으로 명확히 드러낸다. 다른 확장을 조회·변경하거나 확장을 삭제하지 않는다.
- `extension-receipt.json`에 중지 시도 전 상태와 복구 단계를 저장하고 `session.json`으로 앱 검증과 복원을 함께 판정한다. 늦은 callback이 완료됐는지 확인하기 전에는 복원 성공을 기록하거나 관리 페이지를 닫지 않는다. 원래 중지된 확장을 활성화하지 않는다.
- 실행 제한으로 중단되면 동일 TaskSpace와 영수증으로 확장 원상복원만 시도한다. 앱 입력과 테스트 전체는 자동 재시도하지 않는다. 복구에 성공해도 중단된 앱 테스트는 실패로 남긴다.
- 버튼 중심이 화면 위로 벗어나 hit-test 대상이 없는 경우에도 실제 FairGround 고정 헤더와 버튼의 부분 노출을 확인한다. 제한된 실제 스크롤 한 번 뒤 snapshot과 두 차례 연속된 안정적인 입력 가능 상태를 확인한 경우에만 클릭을 한 번 재시도한다. 알 수 없는 overlay, disabled·중복 버튼, 완전히 화면 밖에 있는 버튼과 입력 dispatch timeout은 실패로 유지한다.

## 캡처 호환성

별도 진단에서 Ego 0.5.1.13은 빈 페이지에서도 PNG 캡처가 시간 초과했고, 기본 DPR 보정 경로 실패 뒤 뷰포트 반감 현상이 있었다. 기능 회귀의 필수 화면 증거는 전체 접근성 snapshot TXT로 남긴다. 실제 마우스·키보드 입력과 모든 기능·네트워크 assertion은 유지하며, PNG 기반 픽셀 검수 성공은 주장하지 않는다.

## 검증 절차

1. 브라우저·DB 연결 없이 설정, 확장 상태 보존, 세션 실패 처리, 스크롤 경계·입력 재시도 제한의 회귀 테스트와 lint를 실행한다.
2. 개발 대상만 설정한 환경에서 필요한 타입·빌드 검증을 실행하고, 정확한 브랜치 커밋의 자동 Preview가 READY인지 Vercel GET 메타데이터로 확인한다. 운영 연결과 배포는 사용하지 않는다.
3. 이 작업에 생성한 TaskSpace 하나를 재사용한다. 변경 불가능한 Preview URL·전체 커밋 SHA·개발 합성 주장 계정과 빈 외부 증거 폴더를 지정하고 `--repeat 3 --isolate-extension aliprice`로 실행한다.
4. 움직이는 카드 1회와 포커스로 정지한 카드 3회, 팀 정보 수정 취소 3회(PNG 선택·제거 포함), 새로고침 후 원래 팀 정보 보존 1회의 총 8개 사례를 확인한다. 취소 뒤 스크롤을 초기화하거나 수동 클릭으로 진행하지 않으며, 취소 구간의 데이터 쓰기 요청이 없음을 검사한다.
5. 사례별 결과뿐 아니라 전체 세션 성공, 확장 원상복원, 합성 계정 로그아웃까지 확인한다. 실패나 늦은 입력이 남았다면 같은 공간에서 관찰하고, 완료를 확인한 경우에만 TaskSpace를 한 번 종료한다. 결과와 복원 영수증은 리포지터리 외부에 보관한다.

명령과 모듈별 책임은 [브라우저 회귀 실행 안내](../../scripts/testing/browser/README.md)에 정리한다.
