# 팀카드 CLUB HERITAGE

2026-10-09 사용자가 선택한 2안과 플래티넘 테두리 반짝임을 적용한 자산입니다.

- 내장 image_gen.imagegen으로 4개 티어의 재사용 가능한 빈 프레임을 생성했습니다.
- 프레임: public/images/team-cards/heritage-v1/*.webp, 1024×1536 RGBA.
- 프레임 안의 FAIRGROUND 문구는 자산에 포함됩니다. 실제 팀 로고와 이름은 공용 Canvas 렌더러로 합성합니다.
- src/lib/team-card-appearance.ts에서 자산 경로·티어 라벨·로고 영역·이름판 좌표를 함께 관리합니다.
- 플래티넘만 테두리·보석 반짝임을 포함합니다. 브론즈·실버·골드에는 추가 광채를 적용하지 않습니다.
- 확정된 대회 결과의 카드 등급을 우선하며, 기권 등 결과 미확정 팀은 기존 리그 등급을 사용합니다. 팀의 DB 리그 소속은 바꾸지 않습니다.
- 검증: 관련 테스트 33개, TypeScript, 전체 ESLint(오류 0), 개발·운영 실제 카탈로그 대조, 정상 Vercel production build.
- 같은 폴더의 프롬프트는 생성 원문입니다. 금지된 방사형 줄무늬가 없는지 실제 자산과 8팀 모음 이미지를 확인했습니다.
