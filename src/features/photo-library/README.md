# 대회 사진 자료실

- `/photos`: 로그인 없이 사진 2,331장 검색·선택·페이지 탐색·원본 확대·개별/ZIP 저장.
- `data/cup-2026.json`: 제공된 공개 폴더의 2026-10-12 목록 스냅샷. 원본은 저장소에 복사하지 않는다. 새 파일 추가/삭제/교체 시 이 목록도 갱신해야 한다. 현재 자동 동기화는 없다.
- `model.ts`: 파일 모델, URL, 파일명 정규화, 용량 제한.
- `download.ts`: 원본 바이트 검증, 취소, 브라우저 저장, UTF-8 ZIP STORE 생성. 재압축하지 않는다.
- `photo-viewer.tsx`: 접근성 대화상자와 원본 확대. 닫으면 다운로드 취소 및 Blob URL 해제.
- `photo-library.tsx` 및 CSS 모듈: 검색, 선택, 페이지, 저장 진행 UI.
- `app/api/photos/[id]/route.ts`: 목록에 있는 ID만 허용하는 스트리밍 전달. 임의 URL이나 ID 프록시로 사용할 수 없다. Google HTML 오류를 사진으로 저장하지 않는다.

## 운영 조건

공개 링크와 원본 다운로드 권한이 유지되어야 한다. Google 전송 제한/권한 변경/파일 삭제 시 원본 요청은 실패하며 재시도 안내가 표시된다. 인증 없는 공개 원본을 서버에서 가져오므로 API 키나 사용자 쿠키가 필요하지 않다. Google 비공식 직접 다운로드 URL의 동작 변경 가능성이 있다.

서버는 원본을 변환하거나 전체 버퍼링하지 않고 스트리밍한다. 원본 트래픽은 호스팅 전송량에 포함된다. 공개 서버 배포에서 큰 파일 스트리밍 및 시간 제한을 확인해야 한다. 브라우저는 한 번에 200 MiB까지 선택 저장하며, 모바일 메모리 상황에 따라 더 적게 선택해야 할 수 있다. 개별 원본은 대화상자의 저장 버튼으로도 받을 수 있다.

선택 목록은 현재 페이지 탐색/검색에서 유지되지만 새로고침하면 초기화된다. ZIP 실패/취소 때는 선택을 보존하며, 전체 다운로드가 완성되기 전에는 ZIP을 저장하지 않는다.

## 검증

`node --experimental-strip-types --test tests/photo-library.test.ts`

실제 브라우저에서 한글 파일명 저장, 8109×5408 원본 보기, 선택 ZIP과 원본 바이트 비교를 확인한다. `npm run lint`, `npx tsc --noEmit`, 개발 DB 카탈로그 검사를 포함한 `npm run build`를 실행한다.

## 2026-10-12 사진 선별

사용자 요청으로 53~78번을 모두 제외했다. 1~52번은 중복 상품 컷을 줄여 7, 16, 22, 26, 29, 33, 43, 51번 8장만 유지한다. Drive 원본은 변경하지 않았으며 파일 번호도 유지한다. 목록을 재동기화할 때 이 선별 기준을 보존한다.

추가 선별에서는 2,570장 중 239장을 제외해 2,331장을 남겼다. 동일 파일명·용량과 미리보기가 일치하는 중복 등록 및 눈으로 확인한 거의 같은 연속 컷만 제외했다. 경기 동작·인물·의미 있는 자세가 다른 컷은 유지한다. `data/curation-2026-10-12.json`에 제외한 ID·파일명·용량·사유를 기록했다. 재동기화 시 해당 ID를 다시 넣지 않으며 복원은 이 기록의 해당 항목을 목록에 추가한다.
